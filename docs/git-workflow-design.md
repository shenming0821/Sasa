日期：2026-10-26。状态：全部范围已实现，自动化、真实 Codex 生成及最终原生浏览交互复核通过。Git 写操作在隔离临时仓库和本地 bare remote 验证；逐项结果与边界见 [验证记录](verification/2026-10-26-git-workflow.md)。

## 目标与范围

在当前工作区完成检查改动、选择暂存、提交与远程同步；保留文件与聊天混合标签，以及 28 DIP 紧凑列表。参考 Mayoi `2ba263790582069d766860103ffac45c7142e399` 的交互结构，独立实现 Fuyu 的工作区归属和异步处理。

| 范围 | 验收条件 |
|---|---|
| 文件与批量暂存 | 文件行提供暂存/取消暂存；多选、分组全部操作；同文件两侧分开选择；含空格、换行、重命名、unborn HEAD、worktree 的实际 Git 测试 |
| 提交 | 每工作区保存独立提交草稿；默认仅提交暂存；无暂存时提供明确“全部暂存并提交”；消息、成功摘要、失败重试可见；未保存文档先显示保存范围，由用户选择 |
| 状态 | 修改/新增/删除/重命名/冲突可区分，颜色辅以文字；增删统计后台按需读取 |
| Diff | 行内/并排、文件与修改块前后导航；按块暂存/取消暂存；操作前检查快照，过时结果不覆盖最新改动 |
| 远程 | ahead/behind、获取、拉取、推送、发布分支；拉取使用 fast-forward，分叉明确报错；真实本地 bare remote 验证，不向用户远程仓库推送 |
| 最近提交 | 分页、摘要/短 hash/时间；每条提交用箭头展开/收起变更文件，按需读取，点击文件在主窗口打开其历史 Diff；保留吸底和独立滚动上限 |
| 丢弃 | 明确范围并确认；已跟踪文件恢复至 index；未跟踪文件移动到本地回收位置；保存草稿不静默覆盖 |
| 冲突 | 三方内容、逐块接受当前/传入/两者、编辑结果与保存；显式标记已解决；进行中的 merge/rebase/cherry-pick 可继续/中止 |
| 分支 | 新建时下拉选择来源本地分支，打开面板默认当前分支，detached HEAD 默认当前提交；成功后切换到新分支；点击列表分支时在当前工作区执行切换，被其他 worktree 占用时显示 Git 错误并保留当前工作区；未保存文档先处理；与左侧项目刷新联动 |
| Codex | 按选定文件/块将解释、检查、修改请求放入对应工作区会话草稿，保留原草稿；提交信息由用户填写，提交区仅提供提交及更多提交操作 |

## 界面

分支切换列表与新建来源下拉均将当前分支排在首位，其余分支保留原有顺序；detached HEAD 时来源下拉将 HEAD 排在首位。

沿用原生字体与现有浅灰主题，主文字、次要灰、主题 success/danger/warning 分工明确。顶部一行分支和远程动作，下面是自动增高提交框和主操作；状态提示独立于列表，不因后台刷新跳动。文件滚动区依次显示冲突、更改、已暂存的更改，空组整体隐藏。默认折叠的最近提交固定在底部；展开后独立滚动，历史区最高占下方可用区的 45%，提交列表最高 260 DIP，保留上方文件列表空间。分组 26 DIP、文件 28 DIP、组间 8 DIP；辅助动作 hover/键盘聚焦出现。主要提交按钮与全局按钮保持状态反馈一致。

Diff 工具栏提供比较类型、布局、前后文件/修改块；并排视图在窄内容区回退行内。新增/删除保留文字符号与色块；块操作绑定实际比较快照。分支选择、丢弃确认与冲突编辑使用窗口内面板或原生确认，不将开发样例放进产品。

首次加载文件差异或在比较中切换文件时，等待代码区布局就绪，将第一处实际增删行滚动到可视区中央；靠近文件首尾时限制在有效滚动范围。行内、并排和窄窗口回退共用此行为，并排两侧同步定位。每种布局只在初次显示时定位，后续刷新同一文件保留阅读位置；二进制和无文本修改不触发定位。验证见[首处差异居中](verification/2026-11-02-diff-centering.md)。

分支工具栏分别使用云端下载、向下入托盘、向上出托盘图标表示获取、拉取和推送，悬停显示对应动作。分支名称后的箭头收起时向右、展开时向下，箭头旋转与面板高度共用 180 ms 过渡；启用系统减少动态效果时立即切换。分支面板在可用宽度内保留左右各 12 DIP 留白，面板和来源下拉使用主题 Surface 配色，长分支名在剩余空间内省略。新建成功清空表单并收起，失败保留输入与来源选择供重试。验证见[分支面板优化](verification/2026-10-30-git-branches.md)。

Git 文件行突出文件名、弱化目录，窄面板优先收缩目录；默认展示增删数并逐项隐藏 0 值，状态字母在行尾。“更改”文件行的增删数和状态字母与悬停操作共用同一区域，悬停或键盘聚焦时替换为打开文件、撤销改动、暂存按钮；共用区域预留两种内容所需宽度，文件名位置保持稳定。已暂存和冲突组保留原有排列。当前 Diff 对应行区分工作区和暂存侧持续选中；分组标题右侧显示中性数量徽标，批量入口在悬停或聚焦时出现。

文件名优先完整显示，路径只使用剩余空间；宽度不足时隐藏路径，仅文件名保留省略号。文字入口右侧留 2 DIP 内边距，接近行尾打开文件按钮的位置。

## 执行与资源

暂存和取消暂存期间保留原列表，不插入过程或成功提示行；写入和真实状态读取在同一后台任务中完成，再一次更新列表并恢复操作。此类索引操作保留最近提交缓存，不触发整项目与编辑文件刷新；相关 Diff 按新快照更新，失败仍读取实际结果并显示错误。

暂存和取消暂存属于快速操作，分支工具栏、提交输入框、提交按钮及文件操作保持原外观，以最终分组变化反馈结果。提交信息可继续编辑；分支、远程、刷新和重复写入在逻辑入口拦截，避免用短暂禁用造成整体变淡与恢复。保存准备、退出和其他 Git 操作继续使用必要的禁用状态。

读取与写入都固定 worktree 根、仓库身份和参数列表；pathspec 使用字面量，文件名使用 NUL 边界。单工作区写操作串行，全局后台槽有界；切换面板不取消已经启动的 Git 写入，结果只回原工作区。退出等待写操作完成，读取可取消。写入错误重新读取真实状态，尤其是提交成功但 hook/推送失败、操作超时及外部 index 改变。

暂存基于明确文件集合；提交不隐式暂存，推送不强推，拉取不隐式 stash/rebase。操作启动前记录范围，完成后刷新状态、相关 Diff、文件和左侧分支。存在未保存文件时显示涉及范围，通过既有保存链等待成功后继续；失败保留草稿与提交信息。

测试只在临时仓库执行写命令；实现期间未对 Fuyu 仓库执行写操作。
