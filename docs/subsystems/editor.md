# 文件、编辑器与 Git

本文记录文件浏览、编辑、保存恢复与 Git 操作的当前行为。历史验收结果与覆盖边界见[文件编辑验证](../verification/2026-10-24-p4.md)和[Git 工作流验证](../verification/2026-10-26-git-workflow.md)。

## 会话文件链接

当聊天文件链接带有有效行列目标时，按编辑区实际可见高度将目标行居中；首次打开先等文本区完成布局再定位。靠近文件首尾时滚动停在可用边界，跳转完成后保留用户后续滚动。

本地文件链接末尾的 `:行号`、`:行号:列号` 作为位置后缀从读取路径中移除，支持相对路径、绝对路径与本机 `file://` 地址。打开文件后按从 1 开始的行列号定位光标并将目标行滚入视口；也支持 `#L行号`、`#L行号C列号` 与 `#L起始行-L结束行`（定位起始行）。路径后缀优先于片段，省略列号时定位行首，越界位置收敛到文件末行和目标行末尾，无效或溢出的行列号不执行定位。首次异步加载完成后应用目标位置；复用标签时基于当前缓冲定位并保留未保存内容。回归与验收边界见[文件链接验证](../verification/2026-11-01-message-file-links.md)。

助手回复中的 Markdown 文件链接单击后在 Fuyu 文件标签中打开；已打开的文件复用原标签及未保存缓冲。相对路径以该会话的工作目录为基准，绝对路径与本机 `file://` 地址也可打开；目录外文件使用其父目录作为文件工作区。路径中的 URL 转义按文件名解码，文件链接的普通标题片段不执行标题定位。

网页与邮件链接继续交由系统处理，消息内部的 `#标题` 链接保留 Markdown 原有滚动行为。其他协议不执行；无效文件地址显示错误，缺失文件沿现有编辑器显示读取失败。完整回复和流式回复复用同一路径。入口见 `internal/ui/message_links.go`；构建脚本的 MyGo 补丁保留内部标题跳转，避免自定义链接回调覆盖它。

## 侧栏入口

顶部保留文件、会话历史、Git 三个入口和独立的侧栏切换按钮。入口点击范围为 36×36 DIP，居中的 30×30 DIP 底色使用 7 DIP 圆角，图标为 18 DIP；选中使用浅灰底与主文字色，未选中透明且图标灰色，移除底部选中线。会话历史使用回转箭头与时钟图标。顶栏保持 46 DIP 高和 4 DIP 按钮间距。

选中状态、悬停、按下和键盘焦点彼此独立；切换面板保留原有历史加载、工作区归属与 Git 刷新取消逻辑。按钮状态规则见[代码标准](../code-standards.md#按钮交互)。

右侧与主窗口之间使用与左侧一致的可拖拽分隔线，文件、会话历史和 Git 共享宽度偏好并跨重启恢复。主窗口和并排 Diff 根据实际侧栏宽度让出空间；默认宽度、调整范围与窄窗口行为见[会话管理](sessions.md)。

## 数据与归属

### 文件右键操作

文件树（含搜索结果）、文件标签和编辑区均提供“复制路径”“复制相对路径”“重命名”“删除”。复制路径使用当前文件的绝对路径，相对路径以该标签或文件树所属的工作区根目录为基准；编辑区同时保留原生复制、粘贴和选择等文本命令。文件编辑区额外提供“复制路径和行号”，按右键点中的行写入 `绝对路径:行号`（右键会先把光标落到该行，行号槽与正文通用），便于粘贴给 AI 指明位置。单文件 Diff 视图同样提供该菜单项，按行映射取新文件行号、删除行取旧文件行号；提交视图等合成路径与并排分栏视图不提供。文件树中的非链接目录行额外提供“在文件夹中搜索”，聚焦文件面板搜索框并把 `./相对路径` 填入“包含的文件”；工作区根本身不填写。Git 面板文件行右键仅提供“复制路径”和“复制相对路径”，相对路径即该行的仓库相对路径。入口见 `internal/ui/editor_actions.go`。

重命名只接受同一父目录下的单个名称，使用系统排他重命名拒绝覆盖已有目标。重命名目录时同步迁移已打开子文件的标签身份、路径、保存基线、未保存缓冲及恢复副本，保留选择、撤销和滚动状态；旧路径重新创建后可独立打开。历史 Diff 仍表示原路径的快照。文件树展开状态和搜索结果随操作刷新，Git 状态重新读取。

删除先展示确认弹窗，再调用 MyGo 的系统废纸篓接口；接口失败时保留文件与标签。未保存的文件先持久化恢复副本，移入废纸篓后保留其标签和内容，并显示文件已删除；用户可使用已有的重新创建入口恢复文件，父目录已删除时须先恢复父目录。干净文件关闭标签。取消弹窗、Escape 或 Cmd+W 保留文件，Cmd+W 只关闭该弹窗。

工作区根、包含已打开工作区的目录、通过父目录符号链接指向工作区外的目标均拒绝重命名和删除；文件读写、检查点或 Git 写操作进行中时提示稍后重试。重命名和删除完成后立即保存标签状态，持久化或恢复副本清理失败时提示实际已经完成的文件操作及未完成部分。验证见[编辑器右键操作](../verification/2026-10-29-editor-context-menu.md)。

`internal/workspace` 负责有界目录读取、自然排序、忽略标记、文件名搜索和文件内容搜索。右侧文件面板由 `internal/ui/editor_view.go` 构建；展开目录才加载子项，搜索列表与目录列表分别维护滚动状态。

文件面板的搜索框只做内容搜索（文件名搜索不再由此输入框提供），布局参考 VS Code 搜索面板：输入框以 `searchField` 容器呈现输入框外观，右缘内嵌“区分大小写”（Aa）、“全字匹配”（ab）和“使用正则表达式”（.*）三个开关；“包含的文件 / 排除的文件”两个输入框由查询框右侧的箭头展开收起，默认收起，收起且存在过滤条件或包含忽略文件时箭头以 Accent 色提示。`workspace.SearchContent` 接收 `ContentQuery`：非正则查询按字面文本匹配，默认不区分大小写，全字匹配按 Unicode 字母、数字和下划线判断边界，正则无效时面板显示“正则表达式无效”。包含/排除为逗号分隔的 glob（`{a,b}` 内的逗号不拆分），以工作区根为基准：`./` 开头锚定到根，其他模式匹配任意层级，`*`/`?` 不跨目录、`**` 跨目录，命中目录时覆盖其下全部文件。排除框内右缘的“使用排除设置和忽略文件”开关默认开启，关闭后也搜索 Git 忽略文件和常见依赖目录。目录重命名时，由“在文件夹中搜索”写入的单一 `./目录` 包含项跟随新路径，删除时清空。

结果先显示“N 个结果，位于 M 个文件”摘要和“全部折叠/展开结果”按钮，再按文件分组：可折叠的文件头显示图标、文件名、目录和命中数徽标，下面每个命中行以 `native.RichText` 高亮匹配片段（`ContentMatch.Ranges` 为预览文本内的 rune 半开区间，预览从首个匹配前约 20 个字符开始，前面截断时加“…”，最长 240 个字符）。点击、Enter 或方向键打开文件并按匹配行列定位光标（复用 `fileLocation`）；方向键选中已折叠文件内的命中时会自动展开该文件。新的搜索清空折叠状态。内容搜索与文件树共用符号链接跳过规则，另跳过二进制与非 UTF-8 文件；单文件上限 4 MiB、每文件 100 行、合计 1000 行、单行最多 100 个高亮区间，超限或文件读取失败时结果标记不完整。不提供替换。“在文件夹中搜索”打开搜索时，若编辑器当前有不跨行且不超过 200 字节的选区，搜索词预填为选中内容；搜索输入每次获得焦点时全选查询文本，直接键入即整体替换。

查看文件内容时，与工作区搜索词匹配的关键词在正文下高亮（参考 Mayoi 编辑器查找的实现）：全部匹配绘制半透明 Accent 圆角块，选区所在的匹配加浓并描边。高亮按 `ContentQuery` 的文本、大小写、全字与正则选项重算（`workspace.CompileContentQuery` + `workspace.IsWholeWord`），与搜索结果一致；不包含包含/排除文件过滤。后台扫描最多保留 20000 个匹配，缓冲编辑约 150 ms 后重扫，清空搜索词即取消高亮。文件内查找（Cmd+F）开启时改用查找词高亮；按 Cmd+F 时若当前有不跨行且不超过 200 字节的选区，查找词预填为选中内容，跨行或超长选区保留原查询；查找栏每次获得焦点时全选查询文本，直接键入即整体替换（与 Mayoi `openFind` 的 SelectAll 一致）。栏内显示 `n/m` 计数；Enter / Shift+Enter / “下一个”在缓存匹配上循环并选中当前匹配，查询输入即时重扫并定位到光标后首个匹配。扫描与结果应用校验缓冲实例、版本与请求代次，跨行匹配按行分段绘制，位置由 `native.ShapeText` 实际排版测量。另有选区引用高亮（参考 Mayoi `findWords` 的选区分支）：无查找栏匹配时，不跨行且不超过 200 字节的非空白选区按子串匹配高亮缓冲内全部出现；每帧仅扫描可见行、最多 400 处，绘制为正文色约 14% 透明的圆角块、无描边，明显弱于查找高亮，选区自身不重复绘制。

读取目录或刷新父目录时，按实际结果移除已删除子目录的展开、子项、动画、选择及过时请求；清理仅作用于导航状态，打开文件与未保存缓冲保留。工作区根目录不存在或读取权限不足仍显示错误。空目录的成功读取以缓存键存在为准，避免将空结果当作尚未加载而逐帧重试；清理后的展开列表随下一次快照保存。

`internal/editor` 负责磁盘版本、编码与换行、保存和恢复副本。UI 的 `filePage` 维护编辑缓冲、保存基线、选择与滚动、撤销栈及加载状态。聊天会话与文件标签各有身份；文件操作直接绑定文档路径，后台聊天事件仍回写所属会话。

鼠标左键在编辑器内定位时，光标立即进入可见阶段，530 ms 后继续正常闪烁；同一行内再次点击也重置计时。该行为由 `scripts/mygo-input-style.py` 中的隔离 MyGo 补丁实现，文件缓冲与普通文本输入共用，右键和单纯悬停保持原逻辑。回归见 `TestEditorClickRestartsVisibleCaretPhase`。

`internal/git` 提供有界状态、差异、历史读取和明确触发的 Git 操作。暂存区与工作区差异独立读取；差异读取重复采样，持续变化时报告重试。普通打开、刷新和恢复保持只读；暂存、提交、远程同步、丢弃、分支及冲突操作只由对应入口触发。监听目录包含 worktree 私有 index/HEAD 所在目录和共享 refs，低频检查作为补充。实际操作结果与验收边界见[Git 工作流验证](../verification/2026-10-26-git-workflow.md)。

Git 首次读取显示加载提示；已有成功快照后，自动与手动刷新均保留当前内容，不插入加载行或改变工具栏按钮外观。列表使用稳定身份保存滚动与焦点，折叠状态独立于请求状态；失败继续显示原快照与具体错误。

Git 面板采用连续文件列表：分组标题高 26 DIP，文件行高 28 DIP，组内无额外间隔，仅分组之间留 8 DIP。分支工具栏高 36 DIP，上游信息保持单行；文件名为主、目录为次，增删数后台读取并直接显示；新增、删除分别仅在大于 0 时显示，两项均为 0 时整组隐藏。文件分组依次为冲突、更改、已暂存的更改；空组整体隐藏，不显示占位提示。默认折叠的最近提交固定在面板底部，与文件列表独立滚动；展开后整个历史区最多占工具栏下方可用区的 45%，内部提交列表最高 260 DIP，上方文件列表保留剩余空间。历史滚动状态按工作区独立保存于运行内存，标题行右侧常驻刷新按钮重新读取第一页。最近提交每页读取 20 条；列表可滚动且距离底部不超过 80 DIP 时自动追加下一页，等待新增内容布局及历史区、提交详情的折叠动画稳定后再判断。读取失败后停止自动重试，保留“加载更多提交”按钮供手动重试或内容不足以滚动时继续加载。Cmd/Ctrl 多选与 Shift 连选按分组隔离，多选后出现批量入口；分组支持全部暂存/取消暂存，「更改」分组在全部暂存前提供撤销全部改动；行内与分组撤销均为两段式就地确认，首次点击转入待确认态，数秒内再次点击执行，执行前沿用撤销范围的核对与复核。

2026-10-26 列表交互优化后：文件名为 12 DIP，目录为弱化的 10 DIP，窄面板优先收缩目录。行尾使用 20 DIP 字母状态（M/U/A/D/R/C/T），通过颜色及状态提示补充含义。“更改”文件行将增删数、状态字母与操作按钮放在同一行尾区域：默认显示增删数及状态，悬停或键盘聚焦时替换为打开文件、撤销改动、暂存三个按钮，提示仅含动作名称。共用区域至少 72 DIP，较大数字按实际文字测宽增加占位，切换显示时文件名与行尺寸保持稳定。已暂存及冲突组保留原操作区、增删数、状态字母的排列，中间操作位留空，分别提供取消暂存或标记已解决。当前 Diff 对应行以淡主题色持续标记，区分工作区和暂存侧；多选使用中性底色，普通文件及历史 Diff 不作为当前 Git 差异。分组数量使用右侧中性徽标，批量入口悬停或聚焦显示并保留占位。

`internal/ui/git_actions.go` 维护每个工作区的提交草稿、选择、动作和异步回调。单工作区写入串行，切换工作区不取消已启动写入；退出等待保存准备和 Git 写入结束。默认提交暂存区；“全部暂存并提交”显式更新所列文件，已有暂存时也可从“更多提交操作”选择。涉及未保存文件时先显示磁盘/保存选择；切换分支只允许返回编辑或保存后切换。保存等待实际成功后继续，失败保留草稿；Git 错误后重读真实状态，不自动重复写操作。

Git 远程操作提供获取、拉取、推送和发布分支。拉取仅允许 fast-forward，分叉时报告错误；推送使用普通推送，发布分支显式设置 upstream，操作过程中保持本地改动，不隐式 stash 或 rebase。丢弃已跟踪文件时恢复至 index，未跟踪文件移动到应用自有回收目录并记录原路径；执行前核对确认范围与未保存编辑。

分支切换和新建来源列表将当前分支置顶，detached HEAD 时新建来源默认当前提交；新建成功后切换到新分支。分支被其他 worktree 占用或操作失败时显示 Git 错误，保留当前工作区和输入。冲突页提供共同祖先、当前和传入版本，可逐块接受当前、传入或两者；保存成功且冲突标记清除后显式标记已解决，进行中的 merge、rebase 和 cherry-pick 由用户继续或中止。

暂存与取消暂存在同一后台任务中完成写入和状态读取，保留原列表、提交输入及工具栏外观，读取真实结果后一次更新；重复写入在动作入口拦截。Diff 首次布局完成后将首处实际增删行居中，刷新同一文件保留阅读位置；差异页提供查看和导航，暂存与取消暂存通过 Git 文件列表执行。`internal/git` 保留块级应用接口与快照校验。提交信息由用户填写，提交区提供提交和更多提交操作。

`internal/ui/git_diff.go` 提供行内/并排切换、文件与块导航；文件行合并路径与操作：相对路径后显示绿/红增删统计，右侧依次提供修改块计数与前后导航、行内/并排分段图标、“打开文件”图标按钮和更多操作；不另设比较类型标签（标签标题保留“· 更改”等比较名）。窄内容区回退行内，并排垂直滚动联动。正文宽度至少填满扣除侧栏后的可用区，并排时各占一半；长行通过 MyGo 实际字体排版测宽，包含中文、字体回退、Tab 与行尾空格，计入内边距；并排两侧按各自 12 DIP 文本独立测量，行内按 13 DIP 测量。使用 `Shrink(0)` 保留横向溢出，滚至最右时完整行尾可见。鼠标位于溢出区域时，MyGo 在底部显示可拖动的横向滚动条，并排两侧分别保留横向滚动位置。首次载入 Diff 即计算内容宽度，刷新正文后重新计算并约束旧滚动位置。选中块以行号侧栏的主题色竖线标记，文本定位更新所选块。块操作固定 HEAD、相关 index 记录及文件字节的 token；过时快照拒绝执行，二进制、重命名、子模块和非普通文件保留整文件操作。历史提交按 20 条分页。底部面板的每条提交前显示展开箭头，点击整行展开/收起；首次展开按需异步读取该提交的变更文件，列表展示文件名、目录与状态，点击文件在主窗口打开该提交对应文件的只读 Diff。读取失败保留重试入口，空提交显示无文件改动；展开和文件缓存按工作区/提交 hash 隔离，收起后复用，历史刷新时清理已移除提交的缓存。子文件共用既有历史独立滚动区与高度上限，展开提交不会撑大面板。快速切换同提交的文件时取消旧读取并校验请求身份，最终显示最后选择的文件。

`diff_rows.go` 将原始补丁解析为代码行和并排配对行，每行分别记录旧/新文件行号、增删类型及所属原始修改块。正文缓冲只包含代码；行号与增删符号在侧栏绘制，文件头、index 行、修改块头及补丁换行说明不进入代码或复制内容。语法高亮按文件类型生成，文件与两种 Diff 共用 GitHub 浅深色主题。工作区差异读取 index 作为旧版本，暂存差异读取 HEAD，提交差异读取第一父提交，外部比较使用固定的本地缓冲；先校验补丁中的旧代码与源版本一致，再补齐块前、块间与块后的未修改代码。源版本缺失或不一致时仅显示可核验的补丁代码，并以 `⋯` 表示已知缺口。二进制与仅元数据变化显示说明；不完整历史的提示独立于代码。原始 patch、token 和修改块编号独立保留，跳转、鼠标选择与修改块定位通过行映射完成；验证见[Diff 代码展示](../verification/2026-10-30-diff-source-view.md)。

### GitHub 编辑区主题

`editor_syntax.go` 集中处理语言识别和编辑区配色；后台高亮保留 Chroma token 类型及 rune 区间，绘制时解析 `github` / `github-dark` 的 token 继承色。切换应用浅深色立即重绘已打开文档，不重新分词；浅色底色/正文为 `#ffffff` / `#1f2328`，深色为 `#0d1117` / `#e6edf3`。编辑区独立设置底色、正文、选区、行号与增删色，工具栏和其他界面继续使用应用主题。原生光标使用解析后的正文色；文件内查找的当前匹配仍用原生选区反馈，其余匹配用 Accent 半透明高亮。光标相邻 `()[]{}` 时配对括号以 Accent 淡底圆角框标记，光标处的括号优先于前一个，只计同类型嵌套，不解析字符串与注释。

Vue 采用 Chroma 规则副本收紧 `v-` 指令的双引号边界，并将 script/style 内容委派给 JavaScript/TypeScript/JSX/TSX 或 CSS/SCSS/Sass/Less lexer。SQL 使用通用 SQL，Brewfile、Makefile、Dockerfile、`.npmrc` / `.yarnrc` 明确选择 lexer；`go.mod` / `go.work` / `go.sum` 避免误识别为其他语言，按正文显示。未知文件和超出既有高亮限额的文件同样回退正文。现有可见区预览、完整文档校正、取消与版本校验保留；并排 Diff 只应用匹配当前缓冲版本的 token。验证见[编辑器主题](../verification/2026-11-02-editor-themes.md)。

文件暂存与批量操作使用相同的未保存编辑确认：选择磁盘版本时仅应用磁盘内容，保留编辑器草稿；选择保存后继续时重新校验 token，保存已改变差异则拒绝并要求刷新。取消暂存只改变 index，保留工作区和编辑器内容。

`internal/ui/git_commands.go` 将拉取固定为 ff-only；分叉由 Git 明确报错，推送不自动强推，远程凭据继续由本机 Git 管理。分支选择器标记其他 worktree 的占用并打开对应工作区。丢弃需确认范围并重新检查 token，已跟踪文件还原至 index，未跟踪文件移至恢复目录下 `discarded/discard-*/content`，同目录 `original-path` 保存原路径；跨卷移动失败会报错并保留原文件。

`internal/ui/git_conflict.go` 在普通文件标签展示共同祖先/当前/传入三个只读源版本和可编辑结果；逐块接受保持其他字节，编辑使用原缓冲与撤销链。保存并标记已解决等待磁盘保存成功且不含冲突标记；普通暂存冲突文件同样检查标记。merge/rebase/cherry-pick（以及 Git 报告的 revert）提供继续和确认中止。二进制、特殊文件和容量受限内容转外部处理。

`internal/ui/git_message.go` 生成提交信息时优先选择暂存差异，附近期提交格式；结果可编辑，生成期间草稿或文件变化则保留原内容。解释、检查、继续修改入口位于差异工具栏的更多操作菜单，将上下文追加至同工作区空闲会话草稿，保留已有输入并等待用户发送。源码、验证与限制见 [工作流验证](../verification/2026-10-26-git-workflow.md)。

文件行的文件名优先占据自然宽度，目录以零 flex basis 只使用剩余空间；文件名仍需截断时，目录宽度缩为零，避免同时出现两个省略号。文字入口右侧内边距为 2 DIP，截断文件名可延伸到行尾操作区附近，悬停切换时位置保持稳定。

Git 文件行图标按钮在创建时只注册一次气泡，内容仅为动作文字，不含路径。MyGo 的多次 `Tooltip` 调用会追加提示而非覆盖；需要不同提示文字时，在创建按钮时传入，避免默认提示和动作提示同时显示。

## 保存与恢复

保存使用不可变缓冲快照，并核对磁盘摘要、文件身份、权限和解析后的父目录路径。父目录移动后由链接重定向时，保存与重新创建均停止。临时文件写入同步后替换源文件；替换后的错误与替换前失败分别报告。保存期间继续编辑时，新文本保留为未保存状态。符号链接、硬链接、混合换行和容量超限内容根据读取结果保持只读。

恢复目录权限为 0700，副本权限为 0600。副本包含源路径、工作区、磁盘基线、编辑正文及摘要，独立于数据库标签引用。临时写入、文件同步、原子替换及目录同步由 `WriteRecovery` 完成。损坏副本保留并提示；其他有效记录继续恢复。恢复和保存失败时保留缓冲，清理副本失败会阻止依赖清理成功的关闭或退出。成功清理会重置检查点版本；后续退出或关闭步骤返回应用时，仍 dirty 的文本无需再次输入就能重建副本。

覆盖确认固定确认前的磁盘版本，用户确认之后再次变化仍触发冲突。外部比较使用本地缓冲与磁盘版本的不可变快照；后续编辑显示比较过时，显式刷新才更换内容。

## Diff 行号标记

Diff 的行号与增删符号通过 `drawDiffLineNumber` 共用文本排版；当行存在增删标记时，在行号后紧接显示 `+` 或 `-`，保留中性行号与增删色。行内、并排布局使用同一绘制入口，选中块竖线位于正文边缘。

## 后台资源与验证

文件任务和 Git 任务各最多并行两个，高亮任务最多一个。目录、搜索、磁盘检查和文件内查找最多占用一个后台文件槽，另一文件槽为显式读取保留；保存与恢复写入使用独立流程。后台结果在主线程检查文档身份、缓冲实例、版本或请求代次后应用。切换工作区取消其目录、搜索、文件加载/检查、文件内查找及 Git 状态/Diff 读取；等待 worker 的可取消任务也能退出，旧回调按请求身份或代次丢弃。关闭文件取消其加载、比较和查找；面板切换/收起时，当前没有 Git Diff 依赖的状态请求取消，已取得结果保留。文件监听只为当前可见 Git 工作区刷新状态。保存与恢复检查点继续绑定文档完成，不随浏览切换取消；原生面板切换的最终复核仍在验收清单内。

高亮先计算视口附近最多约 200 行（含前方约 50 行上下文），主线程接收预览后再接收完整词法结果；预览可能缺少更早的多行状态，最终整篇结果补齐。编辑、撤销/重做、替换缓冲及关闭时取消旧任务，排队任务也能取消并清理文档状态。大文件只读模式跳过词法装饰，保留文本和宽度计算。两阶段结果均校验缓冲实例和版本。

`editor_budget.go` 维护未保存文本、缓存、高亮和撤销预算；Git patch、并排缓冲与冲突源版本计入文档缓存。隐藏文档按最近访问顺序释放可丢弃缓存，未保存正文保留。工作区失去界面及文档引用后释放监听。Git 行统计最多缓存 100 项的计数，完整 patch 不在列表重复保留。

回归入口为 `internal/editor/file_test.go`、`internal/editor/save_test.go`、`internal/editor/crash_test.go`、`internal/workspace/tree_test.go`、`internal/git/status_test.go` 和 `internal/ui/editor_*test.go`。保存和恢复通过私有 IO 操作边界注入写入、同步、替换及核验错误，公开接口始终使用真实磁盘实现。隔离子进程在保存/检查点替换前后向自身发送 SIGKILL，由父进程核验源文件和完整恢复记录；进程崩溃与断电保证分别处理。实际恢复清理权限故障与扩展属性保留另用真实临时文件验证。性能样本显式设置 `FUYU_P4_PERF=1` 执行；容量门控纳入普通回归，内存渲染器结果与真实窗口验收分别记录。
