# 存储与恢复

## 数据与归属

`internal/storage/store.go` 使用 `modernc.org/sqlite v1.60.1` 保存应用索引。macOS 默认路径为 `~/Library/Application Support/Fuyu/fuyu.db`，可通过 `-data-dir` 指定独立目录。

数据库保存会话 ID、原生 thread ID、cwd、标题、草稿、选中会话、侧栏开关与宽度、项目折叠、历史面板开关、阅读锚点和条目内偏移、工具展开状态，以及未确认任务标记。消息、工具正文由 Codex 原生历史提供；凭据、待处理协议请求和秘密表单答案不写入应用数据库。用户主动输入的草稿属于本地持久数据。

`fuyu.lock` 通过非阻塞独占 flock 防止两个进程同时使用同一数据目录；进程退出后操作系统释放锁。新目录权限 0700，数据库权限 0600。绑定规范化后的 `CODEX_HOME`（默认 `~/.codex`）；使用其他原生历史目录时要求独立应用数据目录。

## Schema 与事务

通过 `PRAGMA user_version` 管理版本：

| 版本 | 内容 |
|---|---|
| 1 | sessions、cwd 索引、settings；原生非空 thread ID 唯一 |
| 2 | runtime_identity，绑定 Codex 历史目录 |

每次迁移在事务内完成；拒绝高于当前支持版本 2 的数据库。损坏或无法解析的记录报错并保留文件，不自动清空重建。

导航布局偏好扩展现有 settings JSON，保持 schema 2。旧记录缺少侧栏宽度时使用 240 DIP；临时覆盖面板和搜索内容只保留在当前进程，窗口自动收起侧栏不会覆盖用户的展开偏好。

数据库单连接，`busy_timeout=250` 毫秒，WAL，`synchronous=FULL`。保存将全部会话元数据与设置置于同一事务，失败回滚。当前没有删除会话功能，保存采用 upsert。

## 保存时机与恢复门控

`internal/ui/persistence.go` 生成快照，比较上次成功保存内容后写入。异步主线程状态更新后保存，500 毫秒周期补存草稿、滚动与展开状态，关闭窗口和退出前再保存。数据库失败显示具体错误，保持重试；发送前的关键状态无法保存时停止提交。

应用重启后，原生历史核验前禁止发送。正常完成的原生任务允许同 thread 新 turn；未结束 turn、原生失联或未知提交继续保留 Active/TurnID。即使多次异常重开，也不能用空闲 UI 覆盖原有不确定标记。没有原生 thread/turn ID 的提交需要显式确认，不能自动重发。

跨进程恢复流程和事件边界详见[会话管理](sessions.md)。数据库只负责应用自身数据，不能据索引内容宣称原生任务成功或原进程已重新接入。

## 验证

`internal/storage/store_test.go` 覆盖重开、唯一归属、事务回滚、损坏保留、高版本拒绝、v1 升级和 Codex 历史目录不匹配。UI 恢复及真实运行见 [P3 验证](../verification/2026-10-22-p3.md)。
