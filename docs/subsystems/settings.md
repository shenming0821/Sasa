# 设置与完成通知

## 已实现范围

设置入口位于左侧栏标题的齿轮按钮，同时支持应用菜单“设置…”和 Cmd+,。浮层分为“外观”“通知”，Escape、关闭按钮及 Cmd+W 关闭设置并保留当前会话；原生关闭窗口时优先收起设置。

外观包含跟随系统/浅色/深色、英文字体、中文字体和代码字体。初始英文字体与代码字体均为 M PLUS Code Latin，中文为现有系统中文 UI 字体。字体列表来自本机与应用注册字体，支持搜索并勾选当前选择，中英文与代码预览同步更新。英文与代码字体分别控制普通内容、代码块/命令/编辑器/Diff；两者共用所选中文回退。主题及字体的标签与控件同行，标签列固定 64 DIP，控件共用对齐边界；字体浮层宽度与触发控件一致，搜索框和列表填满内部可用宽度，长名称单行收缩。字号、密度及发送行为继续使用现有值。

## 状态与保存

`storage.Snapshot.Preferences` 保存应用级设置，复用 SQLite settings JSON，不新增数据库版本。旧快照没有 Preferences 时采用默认值：主题 system、后台完成通知开启、通知声音关闭。选项修改立即持久化，成功后生效，保存失败恢复旧值并在页面显示错误。字体名称不可用时由字体回退链处理；字体列表随应用重启刷新。

运行时主题通过 MyGo ThemeSource 设置，跟随系统时保留系统强调色和无障碍偏好；组件测试使用对应主题模拟。Markdown 与显式代码字体共用同一设置源。代码或中文字体变化时取消旧测量、清空已打开文件的宽度缓存，使用同一字体重新测量编辑器与 Diff 横向范围，旧字体异步结果不得覆盖当前宽度。

## 任务完成通知

仅在真实事件链中接收到本会话从 Busy 转为空闲的 `turn/completed` 且状态 completed 时考虑通知。窗口在后台、当前显示其他标签或设置页时提醒；正在查看当前会话时保持安静。中断、失败、恢复历史、断线和重复终态不发完成通知；退出流程也不提醒。

通知使用 MyGo 系统通知，按会话替换和分组，文案为“任务已完成”及会话标题；系统通知正文不包含回复正文。提示音由通知 Silent 控制，仅对开启的完成通知生效。点击通知打开对应会话。系统不支持或权限拒绝时在通知设置显示错误，不阻断会话。

本轮不含字号、内容密度、发送方式、默认模型、Diff 行为及待处理事项通知设置。实际验证见[设置验证](../verification/2026-10-27-settings.md)。
