# 本轮文件变更汇总

## 呈现与归属

`internal/ui/commands.go` 从会话消息投影列表行。同一轮次内所有成功文件编辑累计为一张卡片，固定落在该轮内容的末尾（最终回复之后）；命令记录仍按正文、审批与归属边界分段成组。卡片在所属轮次输出完毕前不显示：投影遇到下一条用户消息即证明上一轮已结束，列表末尾的当前轮则以该用户消息的 `Timing.Finished` 判定。轮次完成折叠为“用时”行时，卡片保留在折叠区之外、最终回复之后。运行中、拒绝、失败的文件编辑保留独立原始记录，不进入末尾汇总。空助手占位消息不拆分汇总。成功调用通过文件行进入历史差异；协议消息保持原始顺序，用于汇总和历史查看。

`internal/ui/change_card.go` 提供与聊天背景一致的细边框圆角卡片：标题单行显示“已编辑 N 个文件”，增删数据仅在每个文件行显示。目录使用相对路径与次要颜色，文件名使用正文色，统计固定右对齐；宽度不足时先缩短目录，优先保留文件名。新增绿色、删除红色，零项隐藏；无净增减和统计不完整明确区分。默认显示前三个文件，通过“再显示 N 个文件”展开与收起。浅色、深色与键盘焦点沿用 MyGo 主题。

成功修改按规范化路径去重，cwd 内的相对路径与绝对路径使用同一标识；重命名沿 `move_path` 保留文件身份。文件数量表示本轮触及文件数，改回原文或新增后删除的文件仍计为触及文件，行统计为净增减。

## 统计来源与边界

`internal/app/change_summary.go` 仅读取本轮协议中的文件内容，不读取当前磁盘或 Git index。逐条应用统一补丁，记录已知初始行和最终行；未知且未改动的内容作为稀疏分段边界，对已知区间进行 LCS，得到合并后的差异。重复替换、改回原文、新增后删除、删除后重新创建、重命名与末尾换行均参与合并，避免直接累加每次调用的行数。

Devin（ACP）的 diff 内容块携带完整文件的 oldText/newText。`internal/devin/update.go` 接收工具开始和更新通知中的内容，以更新后的快照替换开始时的占位数据，并投影为从文件开头覆盖全部内容的统一补丁，kind 标记 `snapshot:true`。汇总逐次核对前一快照的完整行数、内容和末尾换行，再计算本轮首个版本与最终版本的净差异。命令执行通知附带的 diff 通过独立文件变更条目进入同轮汇总，保留原命令记录。实时通知与历史回放使用相同的快照投影。

缺失修改后内容或只有空占位的通知保持不完整。既有 `region:true` 无位置区域记录继续使用保守合并：只在文件此前没有记录时合并，后续区域不猜测位置。重新加载 Devin 原生历史后，按原生通知中的完整快照重新投影。

缺失/格式错误/前后冲突的补丁、被截断的文件内容以及超过计算预算的内容，标记为“统计不完整”，不显示推测的数字。差异入口按顺序保留已有原始补丁并显示记录不完整提示。补丁最多展开到 100,000 行，每个已知区域的 LCS 矩阵最多 1,000,000 单元；这些是计算保护，超限不影响查看已保存内容。

`FileChange.Truncated` 标记 UI 投影裁剪了文件补丁；`State.DisplayTrimmed` 标记显示预算移除了早期条目。当前轮存在协议缺口，或最早显示的轮次缺少开头时，卡片同样不将局部统计当作完整结果。摘要缓存最多 64 张，签名包含工具状态、路径、补丁和截断状态，协议数据变化时重算。

## 查看历史差异

点击文件行直接打开该文件的历史差异。使用既有只读 Diff 页面，支持行内/并排、修改块导航、文件选择器和上/下一个文件。数据来自卡片冻结的协议补丁；正常 Git 刷新与 Git 刷新失败均不替换该内容，也不提供暂存修改块、丢弃或向 Codex 发送当前 Git 修改块等工作区写入口。删除文件禁用“打开文件”；其余文件打开入口仍指向当前磁盘。页面头部为一行：相对路径文件选择器与该文件绿/红增删统计居左，右侧依次提供修改块计数与前后导航、行内/并排分段图标、“打开文件”图标按钮和更多操作。比较类型只显示在标签标题中。

历史差异页是临时查看标签，本轮不将补丁正文复制进应用索引。退出后回到原会话，重新加载原生历史后可从卡片再次打开；其他文件、普通 Git Diff 标签与草稿按现有机制恢复。文件缓存回收后从冻结的本轮内容重新构建，不读取当前文件作为替代。

截图中的撤销操作本轮暂缓，沿用此前确认的分步范围；当前卡片只呈现已实现的查看入口。可靠撤销需要独立设计任务结束后新增编辑的保护规则。
