# Fuyu 文档入口

继续开发时，先阅读[实施计划](implementation-plan.md)中的“当前接续点”，然后核对工作区实际状态。

| 文档 | 用途 |
|---|---|
| [实施计划](implementation-plan.md) | 当前进度、四步实施顺序、验收要求与中断接续方式 |
| [设计文档](design.md) | 范围、架构、状态、原生交互及恢复约定 |
| [参考项目核验](reference-verification.md) | 固定源码、协议依据与尚待运行验证的边界 |

实施计划是进度的统一记录入口；设计文档保留设计约定，参考核验保留证据来源。
