# 会话按需加载与标签关闭验证

日期：2026-10-23。

## 行为与范围

原实现启动后为所有本地索引会话显示标签，并逐个请求原生恢复。本轮将历史索引与已打开标签区分：启动只打开按既有 cwd 规则选中的会话，并只恢复其原生历史；点击其他项目会话或原生历史时才打开并恢复。索引仍读取元数据，未打开会话不加载原生消息正文。

每个标签右侧显示独立关闭按钮。关闭保留侧栏记录、草稿、阅读和工具状态；运行中的任务与审批继续归属原会话，退出保护继续包含它们。关闭当前标签优先选择左邻，再选右邻；关闭最后一项新建同目录空白会话。已加载会话在当前进程中保留状态，重新打开不重复恢复；重启仅打开选中项，不恢复此前全部标签。

未打开的历史保留未确认 Active/TurnID 和阅读数据；保存不会用空白投影覆盖它们。标签关闭不会调用原生中断、删除历史或释放任务归属。

## 自动化验证

`internal/ui/tabs_test.go` 使用临时 SQLite 索引、受控恢复后端和 MyGo 组件测试，不读取真实用户配置或发送模型任务。

- `TestStartupLoadsOnlySelectedTabAndOpensHistoryOnDemand`：三个索引记录仅显示选中标签；启动只请求其恢复；点击另一项才请求恢复；关闭重开保留草稿且不重复请求；保存保留未加载记录的未确认任务与阅读状态；再次启动只打开选中项。
- `TestCloseTabsPreservesBackgroundWorkflowAndLastTabFallback`：关闭后台标签不切换当前选择；审批与原生终态仍回到原会话；退出保护保留活动任务；重新打开保留草稿和工具展开；关闭当前项切换邻居，关闭最后一项新建空白会话。
- `TestClosingRecoveringTabDoesNotReopenOnLateResult`：恢复期间关闭标签，晚到的恢复结果不重新打开标签或抢占选择。
- `TestTabCloseButtonLayout`：640、1000 DIP 窗口关闭按钮可见，点击区域至少 24×24 DIP，与标题不重叠。
- 既有导航回归继续覆盖多标签横向滚动、选中标签滚入视口与侧栏切换。

已通过：`./scripts/go test ./...`、`./scripts/go vet ./...`、`./scripts/go test -race ./...`、`./scripts/build`。
