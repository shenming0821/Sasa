# Claude 关闭会话内存回收

日期：2026-11-02。

## 实现

原 UI 的 `canReleaseRuntime` 将回收限定为 Codex。Claude 虽已有 2 分钟空闲超时和最多 4 个空闲进程的保护，关闭页签后仍保留消息及渲染缓存。

移除 UI 的 Agent 类型限制，按后端 `IdleThreadReleaser` 能力派发。Claude 实现该能力：持锁核对任务与进程归属，活动/unknown 状态保留；空闲进程转入 retiring 后在锁外关闭并等待退出，再通过原生历史恢复检查，最后核对进程代次和空闲状态。历史可恢复后复用 UI 的保存、缓存清理及重开恢复机制。

界面保留草稿、阅读锚点、工具折叠状态和标题。空闲进程已经过期时仍可清理缓存；原生历史缺失、变化或损坏时保留显示缓存。运行中任务、待审批、后台工具与未确认状态沿用既有保护。

## 验证

- 定向测试已通过：Codex/Claude 的 30 秒保留、重开恢复、回收期间重开、任务保护；Claude 自有进程退出与重新启动续聊、未知任务与历史缺失保护。
- `./scripts/go test ./... -timeout=120s`：全量通过，Claude 包约 13 秒，UI 包约 21 秒。
- `./scripts/go vet ./...`：通过。
- Claude/UI 回收、回收中重开、任务保护、空闲进程及复用轮次的定向 race：通过。
- `./scripts/build` 和 `git diff --check`：通过。
- 正常退出旧实例并启动新版 PID 43584，原 Claude 空白页签 92 恢复，主窗口可用。打开一条已有 Claude 历史，关闭后等待超过 30 秒，再从历史列表打开，原问题、回复和“用时 22秒”恢复，输入框可用；测试结束关闭该页签，回到原页签 92，并恢复 Git 面板。

自动化使用临时目录、Python 合成协议子进程及 MyGo 内存渲染器。进程退出和新进程续聊由本机受控子进程验证，原生窗口补验已有真实历史的关闭与重开；未调用真实模型，未测量原生 RSS 降幅。原生窗口恢复不能单独证明缓存已经释放，缓存清理及重开门控由定向回归覆盖。
