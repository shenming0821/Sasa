# Cmd+W 关闭当前页签

日期：2026-11-02。

## 原因与实现

MyGo 默认 `RoleFileMenu` 在 macOS 下生成 `RoleClose`，将 Cmd+W 原生绑定到 `performClose:`。该动作先于 Fuyu 的渲染层快捷键处理，触发窗口关闭回调并隐藏窗口。

“文件 → 关闭当前页签”显式绑定 `CmdOrCtrl+W`，通过 `App.update` 派发到 `closeCurrentPage`。渲染层、编辑器焦点和终端快捷键复用该动作。弹层优先关闭，文件确认期间保持状态；关闭最后一页后保留空工作区。
