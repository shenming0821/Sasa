## 行为与参考

参考 Mayoi `cd08688ade5ece3411d9bb812228c7d30492526a` 的 `diffrows.go`、`diffview.go`、`diffhunks.go`，采用代码行、旧/新行号与原始修改块身份分离的方式，自行实现适配 Fuyu 的行映射。

- 行内与并排正文显示代码，增删行使用红/绿背景和侧栏符号，所属选中块有主题色侧栏竖线。
- 文件头、index、`---` / `+++` 文件标记、`@@` 修改块头及补丁末尾的换行说明不进入代码正文；源代码自身含有这些字符时按真实内容保留。
- 工作区、暂存、提交和外部比较从对应旧版本补齐前后及块间的未修改代码；补齐前验证补丁上下文。缺少源版本或校验失败时使用补丁可核验行，已知缺口以省略行表示。
- 原始 patch 与快照 token 保留，暂存操作继续使用原始修改块。并排空位、独立横向滚动、垂直同步及窄区回退行内保持可用。
- 会话历史不从当前磁盘推测旧版本；不完整记录提示在代码区域之外展示。二进制与仅权限/路径变化显示文字说明。
