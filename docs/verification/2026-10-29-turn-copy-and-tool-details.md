# 按轮复制回复与空工具详情

日期：2026-10-29。

## 行为

同一轮执行完成后，仅最后一段非空助手回复显示一个复制按钮。复制内容按顺序拼接本轮全部助手回复的原始 Markdown，以空行分隔；用户输入和工具记录不加入复制。当前轮执行期间隐藏该轮复制入口，先前已结束轮次的复制入口继续保留。分组同时识别用户输入边界与原生 TurnID，覆盖新会话和恢复的历史记录。

工具记录没有输入、结果和截断提示时显示普通摘要行，保留工具名称、执行状态及耗时，不提供可点击或键盘展开的入口，也不显示“暂无详情”。后续收到详情时恢复展开能力；已有展开状态不会让空详情重新出现。有输入、结果或截断提示的记录继续支持展开和复制。

## 验证

- `TestReplyCopyWaitsForTurnAndCombinesSegments`：执行期间无复制入口；结束后只在最后一段提供复制；中间夹有搜索记录时仍复制全部助手回复；未完成文本不提供复制。
- `TestReplyCopyKeepsTurnsSeparate`：新轮执行不影响上一轮复制；带有或缺少 TurnID 的用户边界保持隔离，历史不同 TurnID 也分别复制。
- `TestToolWithoutDetailsHasNoDisclosure`：覆盖 webSearch、mcpToolCall、dynamicToolCall；空内容和空白内容无箭头，执行状态保留；收到输入后可展开，内容清空后已有展开状态也不显示空面板。
- 会话布局、工具展开与复制、过程记录紧凑间距的既有回归通过。
- `./scripts/go test ./...`、`./scripts/go vet ./...`、`./scripts/build`、`git diff --check` 通过。UI 全量测试用时 22.094 秒。
