## 资源释放实现

- 标签关闭后保留 30 秒；已重开的标签继续复用。
- 在 UI 状态和原生状态两侧核对任务、交互、后台终端及不确定状态；仅回收已确认空闲的自有订阅。
- Fuyu 自有 App Server 使用 `thread_unload_delay_secs=0`，应用执行 `thread/unsubscribe` 后由原生卸载资源；不修改用户全局配置。
- 回收前保存，失败后保留连接并在 1 分钟后重试。原生忙碌或检查失败同样在 1 分钟后再检查。
- 已关闭且确认回收后释放消息与渲染缓存，重开恢复原生历史与草稿。取消订阅结果不确定时保留显示并要求恢复；卸载中的标签重开等待结果，恢复完成前禁止发送。
- 删除会话后也回收其可释放订阅，回调不得重新写入已删除会话。
