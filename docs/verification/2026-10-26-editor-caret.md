# 编辑器鼠标定位与光标闪烁

日期：2026-10-26。

## 原因与修复

锁定 MyGo 的 `ui/input.go` 在焦点改变时重置 `blinkStart`，但已聚焦编辑器内的再次左键点击直接调用 `editor.press`，未重置闪烁计时。`ui/textarea.go` 每 530 ms 切换可见/隐藏阶段，因此点击时若处于隐藏阶段，新位置会延迟显示光标。

在现有 `scripts/mygo-input-style.py` 隔离补丁中，为已布局编辑器的左键定位重置计时。修改不写入共享模块缓存；右键、悬停及原有选区定位继续使用框架逻辑。

## 自动化结果

`TestEditorClickRestartsVisibleCaretPhase` 分别使用普通文本区域和 `TextAreaBufferBase`，以可控时钟进入隐藏阶段，点击不同空行及同一行，核对实际选区位置和光标像素。点击后立即可见，500 ms 后仍可见，540 ms 后隐藏，证明恢复正常闪烁。补丁前两组均在“点击后立即可见”断言失败，补丁后通过。

- `./scripts/go test ./...`：通过。
- `./scripts/go vet ./...`：通过。
- `./scripts/build`：通过。

## 原生窗口

原 `bin/Fuyu.app` 正常退出并重新打开，`.editorconfig` 编辑内容加载正常。鼠标点击后状态栏从 `10:1` 更新为 `15:7`，文件未改动。GUI 工具观察存在延迟，未用截图证明亚秒级光标时序；该时序由上述像素与可控时钟回归验证。

本轮改动已提交。文件编辑与 Git 其他验收边界以实施计划为准。
