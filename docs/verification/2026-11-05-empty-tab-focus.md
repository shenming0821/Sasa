# 空面板页签与聚焦关闭

日期：2026-11-05。

空面板的标题栏显示“新标签页”，复用普通页签的宽度、选中样式和关闭按钮；创建会话或终端后由实际内容页签替换。关闭空页签时，多面板布局移除对应面板，最后一个面板继续保留内容选择入口。该显示由空面板状态派生，无需新增持久化页签类型，Codex 与 Claude 共用。

点击面板空白处时，同时更新布局选择和键盘焦点。执行关闭动作前，从聚焦面板重新取得其当前页签，避免采用逐面板渲染期间留下的其他页签选择；弹层优先、未保存文件确认和后台任务停止继续使用既有流程。

## 自动化

- `TestPaneEmptyContentLayout` 覆盖三个窗口宽度及浅深色下的“新标签页”和内容选择布局。
- `TestPaneEmptyTabCloseAndContentReplacement` 覆盖空页签关闭、邻居保留、末面板保留及新建会话替换。
- `TestPaneCloseShortcutFollowsBlankAreaFocus` 覆盖左右面板空白点击的布局与键盘焦点，以及快捷键、应用菜单关闭右侧面板。
- `TestPaneCloseUsesFocusedTabSelection` 覆盖全局页签选择过时且聚焦面板有多个页签时，只关闭该面板选中的页签。
- 通过 Go overlay 将焦点与关闭实现替换为修改前源码，两个焦点回归均失败；当前实现对应回归通过。
- 全量 `./scripts/go test ./...`、`./scripts/go vet ./...`、分屏/关闭/文件夹页签定向 race 与 `git diff --check` 通过。
