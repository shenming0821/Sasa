# 连续工具操作合并展示

日期：2026-11-03。

## 行为与边界

- UI 投影将同轮、同父任务的连续 commandExecution、dynamicToolCall、mcpToolCall、webSearch 合并。助手正文、用户输入、文件变更和审批交互分隔工具组，空助手占位不产生可见分隔。
- 组标题显示“运行了命令”，运行时显示“正在运行命令”，均不显示次数；失败、拒绝、等待原生终态确认继续显示。工具结果的 isError 也计入组失败，运行期间已有失败时标题保留提示。
- Read/Edit/Write 摘要提取文件路径，Bash 提取命令，ToolSearch/WebSearch 提取查询词，Grep/Glob 提取模式，WebFetch 提取 URL。已识别工具参数缺失或解析失败时显示工具名，其他工具沿用既有标题逻辑。
- 摘要单行省略，详情保留原始输入、输出、复制、截断和错误提示；历史和 Runtime 协议格式保持原有结构。组 ID 沿用首项 ID，旧的单项阅读锚点可恢复到所属组。
- 展开与收起继续使用 MyGo 折叠动画，暂停底部跟随，保护当前阅读位置；追加操作保留展开状态。

- `./scripts/go test ./... -count=1 -timeout=180s` 通过，其中 UI 包 21.976 秒。
- `./scripts/go vet ./...`、最终 UI vet 与 `git diff --check` 通过。

- UI 回归覆盖工具主要内容、未知工具旧标题、缺参/异常参数、320/800 DIP 长路径单行显示、运行到完成、工具结果错误与等待终态。
- 滚动回归覆盖普通及减少动态效果，在列表底部首次展开和阅读途中展开/收起组及 Read 详情均保留偏移，返回末尾后新输出继续跟随。折叠动画尚处起点但目标已改变时即暂停跟随，避免首次展开追底。
- 首次全量运行中两个旧布局断言按原分行规则失败，更新为混合组后通过；另有 Git 修改块暂存用例一次等待超时，单独复跑与最终全量均通过，未修改 Git 实现。

- 相关 UI race 回归通过：`./scripts/go test -race ./internal/ui -run 'Test(MixedTool|ToolOperation|LongRead|ProcessRecords|TimingLayout|Command|TurnProcess|ConversationProjection)' -count=1 -timeout=180s`，11.843 秒。
- 最终 `./scripts/build` 通过，包含应用及 libghostty 签名。

测试中的协议输入和内存渲染器属于受控验证，不代表真实模型调用验收。
