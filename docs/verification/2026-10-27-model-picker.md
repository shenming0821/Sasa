# 模型单选菜单验证（2026-10-27）

## 实现范围与协议

输入区模型按钮打开单选菜单，仅提供 Runtime 返回的非隐藏模型，默认配置对应模型直接选中；当前选择勾选、选中收起、下一条消息生效，任务运行及恢复阶段禁止改选。选择按会话保存并在重开后恢复，分叉继承。运行详情移至底部，使用两列可读值，移除重复快捷键说明，恢复入口改为“重新加载会话”。

协议依据已安装 Codex 生成的 `v2/ModelListParams.json`、`ModelListResponse.json`、`ConfigReadParams.json` 和 `TurnStartParams.json`。`turn/start.model` 影响本轮及后续轮，因此默认项通过 `config/read(cwd)` 取得模型并显式提交，避免之前的覆盖残留；未配置时回退目录默认项，无法取得时保留草稿并报错。配置只读，不写全局配置或权限。

## 受控验证

- 协议子进程验证模型分页、过滤隐藏项、目录 ID 与模型值不同、读取 cwd 配置及目录默认回退、重复 cursor 保护；模型与文字/技能/图片共用一条 turn input。
- UI 验证菜单选中收起、当前勾选、跨会话隔离、SQLite 重开恢复、运行期间禁改、切回默认及可读运行详情。
- 异步发送期间切换会话，模型与结果仍属于原会话；显式默认覆盖旧模型，技能/图片保留。
- 模型目录失败后重试、默认配置读取失败保留草稿且未发送；640×480 DIP 深浅主题菜单边界及 Escape 关闭。
