UI 测试、vet、正式构建通过。在隔离的 1000×760 原生窗口检查两侧展开、逐个收起、再展开：按钮位置正确迁移，原“关闭历史”入口被替换，中文草稿保留。截图与无障碍树均检查通过；测试实例已退出，用户原窗口保留。本次窄窗口由组件测试覆盖。

## 当前修正：历史固定在窗口右侧

用户指出 Orca 的历史直接位于窗口右侧。当前实现已按此修正：展开历史时占据窗口内部独立列，中间会话缩窄，选择历史后保持侧栏展开。常规历史宽度 320 DIP，窄窗口最小 240 DIP，给中间会话保留至少 400 DIP；空间不足时优先收起左侧项目。

组件回归新增边界断言：1400、1000、640 DIP 窗口下，历史位于输入区域右侧，发送按钮和输入不被遮挡；选择历史后面板仍存在。全量 test、vet、race、正式构建和差异检查通过。

使用相同隔离 bundle 和协议夹具，在正式初始尺寸 1000×760 原生窗口检查截图：左侧项目、会话和历史三栏并排；历史为独立全高列，中文草稿和发送按钮均在中间区域内。点击已有历史后右侧栏保持显示。测试实例随后退出，用户原窗口保留。

下面保留首版验证过程作为修改依据；其中右侧历史覆盖面板、自动收起的行为已由本节取代。当前 640 DIP 并排效果通过组件测试验证，修正后的 640 DIP 原生窗口未再次打开验收。

## 首版实现范围

参考用户确认的 Orca 布局，结合 `frontend-design`，使用既有原生主题和字体整理项目、当前会话与历史三个区域。消息、工具、审批、发送与恢复继续复用原实现。

- 左侧默认 240 DIP，可通过原生分隔线调整，应用限制为 200–320 DIP；按完整目录分组，提供标题/路径搜索、项目折叠和打开项目入口。
- 中间增加横向会话标签；切换/新建时选中标签进入可见区域。
- 右侧历史宽 320 DIP，默认关闭；当前项目/全部项目筛选，搜索明确限于已加载历史，可继续分页。
- 低于 1180 DIP 收起历史，低于 900 DIP 收起项目；工具栏提供临时展开入口，选择会话后收起覆盖面板，放大后恢复原偏好。
- 侧栏宽度、项目折叠和历史开关随现有 settings JSON 保存，旧记录使用默认值，数据库仍为 schema 2。
