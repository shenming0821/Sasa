# 会话文件链接打开验证

日期：2026-10-29。

## 行为

单击助手回复中的本地 Markdown 文件链接，在 Fuyu 编辑器打开对应文件。相对路径绑定消息所在会话的 cwd；支持绝对路径、本机 file URL、中文与空格，已打开的文件复用标签及未保存缓冲。网页与邮件链接交给系统处理；内部标题链接沿用 Markdown 滚动。文件链接的片段本轮只打开文件，不定位行号或标题。

## 自动化

使用临时文件、受控后端及 MyGo 内存渲染器，无真实模型调用。覆盖完整/流式回复的实际点击、多会话 cwd、URL 转义、本机 file URL、目录外文件、重复打开及未保存内容保留、缺失文件错误、网页跳转和不执行其他协议。

通过完整 `./scripts/go test ./...`（UI 包 17.508 秒）、`./scripts/go vet ./...`、定向链接测试的 race、`./scripts/build` 与 `git diff --check`。原生验收后补强重复点击与未保存内容用例，再次执行定向测试及 race。
