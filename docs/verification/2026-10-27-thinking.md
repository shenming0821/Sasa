# 思考提示重影修复（2026-10-27）

## 原因与调整

原 `thinkingIndicator` 先用主题 Text 绘制灰色文字，再在 DrawOver 中按像素列裁切并调用 Painter.Text 绘制扫光。Painter.Text 仅指定字号，没有继承主题 Font，造成两层字形与基线对不上；即便位置一致，重复合成抗锯齿边缘也会加重文字。

改用单个 RichText 排版四个字，按当前动画阶段改变各字颜色，共用字体、位置和基线。保留次级灰色、1.8 秒循环、当前请求可见性判断及 ReduceMotion 静态显示。

## 验证

- 新增逐帧字形检查，应用实际 M PLUS Code Latin / 苹方回退字体，对比单层文字掩码；原实现深浅色均可复现字形外多余像素。修复后在 10 个动画阶段均无超出单层字形的明显绘制，忽略灰度差不超过 8/255 的边缘栅格取整差异。
- 原有思考提示生命周期、深浅主题扫光变化和减少动态效果静态测试通过。
- 受控截图 `/tmp/fuyu-thinking-reference.png`、`/tmp/fuyu-thinking-animated.png` 已检查，分别为单层参考文字与修复后的动画帧。
- 完整 UI 测试通过（14.844 秒），vet、构建及差异检查通过；原应用已通过 ⌘Q 正常退出，确认旧进程结束后重开。未重新向模型发送真实任务，待用户在实际等待阶段复核观感。
