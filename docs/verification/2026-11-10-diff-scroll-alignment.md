# Diff 滚动后的背景与行号对齐

日期：2026-11-10。

Diff 正文由 MyGo 按实际字体排版，增删背景与行号此前按“行索引 × 20 DIP”计算位置。框架的固定行高仍会为更高的回退字形扩大行框；混合中文、Emoji 等内容时，已测量行与未测量行的估算高度还会随滚动更新，导致正文与装饰累积错位。

行内视图及并排两侧均通过 `TrackLines` 取得当前帧正文排版，使用 `TextLines.At` 确定可见行、`Top` 确定行顶与背景高度。行号、增删背景和当前修改块标记共用这组坐标。编辑器共用的查找与括号标记同时使用实际行顶。

自动验证使用临时项目和 MyGo 内存渲染器：

- `TestGitDiffScrolledRowAlignment`：600 行中混合中文与 Emoji，第 494 行修改；覆盖行内、并排原版本、并排新版本和窄窗口回退。反复上下滚动后，将增删背景位置与正文实际行顶比较，并将行号区域与同位置的参考绘制逐像素比较。
- 修复前，混合字形用例中正文行顶为 449 DIP，而新增背景位于 362 DIP，复现累积错位；修复后上述用例通过。
- `./scripts/go test ./internal/ui -count=1` 通过，包括现有编辑器、Diff、查找、括号和布局测试。

原生验证：构建并运行 Preview，窗口正常打开。从 Git 更改列表打开真实 `internal/ui/editor_view.go`，在行内视图上下滚动后，红绿背景、行号和正文对齐；切换并排，分别在原版本、新版本区域滚动，背景与行号继续跟随对应正文。原生验收使用浅色主题与当前仓库文件，混合 Emoji 的累计高度差由上述内存渲染回归覆盖。

该修复不涉及模型协议；真实 Codex 与 Claude Runtime 未专项运行。
