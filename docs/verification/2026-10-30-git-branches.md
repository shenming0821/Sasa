# Git 分支面板优化验证

日期：2026-10-30。

## 点击分支统一切换

按最新要求，列表展示分支名和当前项标记；点击其他分支时统一调用当前工作区的 Git 切换流程。被其他 worktree 占用时保留 Git 的拒绝结果，错误显示在当前面板，工作区、会话草稿和提交信息保持原归属。原先跳转到其他工作区的行为已替换。

临时仓库回归先点击占用分支，确认错误、面板及原工作区保留；随后点击未占用分支，确认实际 Git 分支切换成功且工作区目录不变。分支组件回归、定向 race、UI vet、构建和差异检查通过。UI 完整测试首次运行在既有未保存编辑暂存用例发生等待超时；该用例独立复跑及 UI 完整测试复跑均通过。

正常退出旧实例并启动新版 PID 72345，System Events 确认 1000×760 主窗口可用。实际切换与占用失败证据来自隔离临时仓库，原生窗口仅确认启动可用。

## 已实现行为

- 获取使用云端下载图标，拉取使用向下入托盘图标，推送使用向上出托盘图标，刷新保留圆形箭头；动作提示保持独立。
- 分支箭头在收起时向右、展开时向下，箭头与面板高度共用 180 ms 过渡，支持中途反向操作。开启系统减少动态效果时立即完成展开与收起。
- 面板宽度在父容器内保留左右各 12 DIP 留白，背景和来源下拉使用主题 Surface，适配浅深色。输入框分配剩余宽度，新建按钮保留完整宽度，分支列表左对齐，长分支名省略。
- “基于分支”列出本地分支，每次打开面板默认当前分支；detached HEAD 默认 HEAD，并可选择本地分支。新建后切换到所创建分支；后台操作捕获点击时的来源，成功重置表单，失败保留输入。
- 来源通过完整本地引用传给 Git，保留现有分支名校验、未保存文档处理和其他 worktree 占用保护。
