## 本轮修正的行为

保存、重新读取会递增文档磁盘代次，旧检查回调按代次丢弃。覆盖确认捕获确认前的磁盘基线，保存仍走摘要/身份复核，后续外部写入触发冲突。正常退出和任务停止超时后的强制退出均进入文件未保存保护。

恢复副本采用自包含记录（文档身份、磁盘基线及正文、编辑正文与校验摘要），同目录临时写入后同步、原子替换并同步目录。每个文档串行写入；总预算检查与写入在进程内串行化。设计已同步实际协议。新增测试用未完成临时文件模拟替换前中断、用稀疏容量占位触发预算失败，并验证最近完成检查点仍可读、下一次成功替换可恢复。该模拟不等于真实磁盘满或断电验收。

`TestSaveFailureStagesPreserveOriginalOrReportReplacement` 通过六类 IO 故障注入：部分写入后返回 ENOSPC、短写未报错、文件同步 ENOSPC、替换 EACCES、替换后读取 EIO、目录同步 EIO。前三项及替换失败保留原文件；替换后的错误明确显示“文件已替换”，实际磁盘为本地文本；各路径无遗留保存临时文件。公开 `Save` 使用真实 IO，测试只替换私有操作边界，不是系统真实磁盘耗尽。`TestSavePreservesMacExtendedAttributes` 使用真实 xattr 写入、保存及回读，确认扩展属性未丢失。

`TestAtomicWriteSurvivesProcessCrash` 在隔离测试子进程中执行真实文件 IO，分别在保存和检查点的原子替换前、替换后，以及已保存文件的恢复副本清理前、清理完成后向自身发送 SIGKILL；父进程核对退出信号、源文件字节及恢复副本。保存替换前磁盘保持原文，替换后为新文，两者都保留先前完成的本地草稿副本；检查点替换前可恢复上一版草稿，替换后可恢复新版草稿，磁盘基线完整；清理前完整副本仍在，清理后不再恢复冗余草稿，两者磁盘均为已保存新文。六个分支重复 3 次通过。替换后终止点在目录同步前，清理后终止点在清理函数完成之后；此项证明进程崩溃后的可恢复性，不代表断电持久性。

`TestCheckpointFailurePreservesLastCompleteEnvelope` 补充恢复写入的部分写入 ENOSPC、无错误短写、文件同步 EIO、替换 EACCES、目录同步 EIO 五个分支，均报告失败并保留可校验的完整副本；目录同步失败时替换已完成，副本为新版，其余分支为上一版。各路径无遗留临时文件。公开恢复写入始终使用真实 IO 实现，并在原子替换前拒绝短写。

`TestDiffDuringContinuousExternalReplacement` 在真实临时 Git 仓库中，由独立 goroutine 每约 1 ms 原子交替替换两个文件版本，同时连续读取六次 Diff。结果只接受一个完整观察版本，或明确的“持续变化，请刷新后重试”；读取前后 index 摘要一致。用例重复 3 次通过，每次约 0.5 秒。此项是受控外部写入，不是真实模型批量任务。
