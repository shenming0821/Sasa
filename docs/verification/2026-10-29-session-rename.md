# 会话重命名验证

日期：2026-10-29。

## 行为

会话标签、项目会话行及右侧历史行的右键菜单增加“重命名”，保留“删除会话”。弹窗预填当前标题，支持保存或 Enter；取消、Escape、Command+W、点击外部关闭时保留原标题。空标题和控制字符提示错误，首尾空白自动清理。自定义标题保存在 Fuyu，优先于原生摘要，展示与搜索同步并跨重启恢复。

尚未打开的历史改名仅建立关闭的本地记录，按 Agent、Runtime、ThreadID 复用身份，不切换当前会话、不恢复或发送任务。保存失败回退原标题，保留输入和错误。

## 自动化

使用临时 SQLite 索引、受控后端和 MyGo 内存渲染器，覆盖菜单、保存与 Enter、取消按钮/Escape/Command+W/点击外部、空白和控制字符校验、草稿与目录保持、刷新搜索、两种 Agent/不同 Runtime 的同 ID 隔离、历史关闭记录的恢复与后续打开、保存失败回退、运行中改名及已删除会话保护。普通测试不调用真实模型。

通过 `./scripts/go test ./...`（UI 包 15.986 秒）、`./scripts/go vet ./...`、`./scripts/go test -race ./internal/ui -run 'TestSessionRename|TestDeleteHistoryMenus|TestHistoryScopeSearchAndExistingSession' -count=1`、`./scripts/build` 与 `git diff --check`。完整测试曾发现未改名历史错误改用本地占位标题、导致原生摘要搜索失效；修正为仅自定义标题覆盖原生标题后，原有历史范围/搜索回归及完整测试通过。

工作区同时存在文件编辑器的并行修改。额外导出仅包含本次会话重命名的索引快照，在隔离目录执行完整 test（UI 包 17.229 秒）、vet 和桌面可执行文件 build，全部通过，确认本次代码不依赖并行改动。
