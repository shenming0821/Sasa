# 命令分组与折叠交互验收

日期：2026-10-23。

## 参考与实现

用户提供 ChatGPT 截图及本机录屏 `iShot_2026-10-23_14.33.14.mp4`，确认采用轻量命令列表，并补充右侧箭头悬停显示、点击展开/收起具有动效。录屏观察到分组层级的切换；单条命令的完整详情为 Fuyu 保留的查看能力。

- 同一 turn 内连续 commandExecution 消息组成一组，默认收起；正文、审批、提问、其他工具与 turn 边界分隔分组。
- 摘要显示当前命令，完成后显示“运行了命令”；失败、等待确认和全部拒绝有对应文字。组内各命令保留各自状态。
- 展开后命令为灰色单行预览，多行脚本合并空白并省略超宽内容；原始命令保持完整。
- 鼠标悬停时加深文字并显示右侧箭头，移开后隐藏；键盘导航时保留焦点和箭头提示。整行可点击，原生 disclosure 支持 Enter / Space。
- 命令组箭头紧接“运行了命令”等摘要文字，间距 8 DIP；长摘要缩短并省略，箭头始终保留可用空间。单条命令详情箭头继续位于该行右端。
- 展开和收起均使用 200 ms 原生高度动画，并配合裁切、内容透明度和箭头旋转；系统减少动态效果时直接切换。
- 单条命令详情在最高 180 DIP 的独立滚动区展示完整命令、目录、进程、退出码、耗时及输入/输出，提供复制命令入口。审批与提问保留原有独立卡片。
- 分组展开状态和单条详情状态独立保存；流式追加和状态更新保留手动选择。虚拟列表、待办定位、快照锚点使用相同分组投影，旧组内命令阅读锚点映射到组顶部。
