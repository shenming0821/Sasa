# 图标按钮居中修复

日期：2026-10-29。

## 原因与修改

纯图标按钮沿用了文本按钮的 6 px 内边距。例如复制回复按钮为 24×24 px，内边距后的内容区只有 12×12 px，实际图标为 16×16 px，图标超出内容区后向右下偏移。添加图片等固定尺寸按钮也存在相同问题。

增加 `quietIconButton`，保留原按钮的背景绘制、提示、禁用态和点击处理，使用零内边距及水平、垂直居中。复制回复、添加图片、侧栏工具、Agent 新建、文件工具和 Git 图标入口统一使用该布局；文字及图文混合按钮保留原内边距。
