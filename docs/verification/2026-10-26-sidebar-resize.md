# 右侧栏拖拽宽度验证

日期：2026-10-26。基线为 `c04b923`，本轮代码和文档随本次提交一并提交。

## 实现

主窗口与右侧栏之间使用与左侧一致的 MyGo Split，分隔线提供横向调整光标、悬停颜色、拖拽与聚焦后的左右方向键操作。文件、会话历史、Git 共用宽度偏好，默认 320 DIP，调整范围 240–520 DIP。布局为主窗口保留约 400 DIP，窄窗口临时缩小侧栏，变宽后恢复偏好；优先自动收起左侧项目的行为继续保留。右侧宽度写入现有 settings JSON，无须数据库迁移；并排 Diff 根据实际侧栏宽度判断是否回退行内。

## 自动化

- `TestRightPanelDividerDragLimitsAndSharedTabs` 覆盖鼠标按下、移动、松开后的宽度变化及光标、左右键调整、三个面板共用宽度、上下限、640 DIP 窄窗口及变宽恢复。
- `TestNavigationSettingsRestoreAndOldDefaults` 覆盖宽度存储与重开恢复，旧记录缺省时仍为 320 DIP。
- `./scripts/go test ./...` 通过，UI 包耗时 13.332 秒。
- `./scripts/go vet ./...` 与 `./scripts/go build -o bin/Fuyu.app/Contents/MacOS/Fuyu ./cmd/desktop` 通过。
- 本轮未新增后台并发路径，未执行 race 检查。

## 原生窗口

原 `bin/Fuyu.app` 已加载本轮构建，窗口中可读取左右两个原生 splitter。聚焦右侧分隔线后通过左右键实际改变宽度，右侧 Git 内容重新排布。正常退出再打开同一应用、使用原数据目录后，调整后的宽度仍保留；没有创建第二个应用或测试数据目录。

工具在原生鼠标拖拽时未稳定命中分隔线，本轮不将该操作计为原生验收通过；鼠标拖拽及上下限以组件输入回归为验证依据。未在原仓库执行暂存、撤销、提交或远程写操作。
