# 首处差异自动居中

日期：2026-11-02。

首次加载 Diff 或切换比较文件时，为行内和并排布局分别记录一次待定位状态。取得代码区实际高度后，以第一条增删行的视觉中心计算滚动偏移，按内容首尾限制范围；并排两侧同步。相同文件刷新保留阅读位置，二进制和无文本差异不定位。提交文件比较补齐 Review 的文件身份，以区分切换文件与刷新。

自动验证采用临时目录和 MyGo 内存渲染器，不调用真实模型、不修改项目索引：

- `TestGitDiffInitiallyCentersFirstChange`：160 行文件第 81 行修改，行内、并排及 480 DIP 窄窗口回退的实际代码区域均居中；手动滚动后刷新保留位置，切换文件重新请求定位。
- `TestGitDiffInitialCenterWaitsForLayoutAndClamps`：布局未就绪保留待定位；两种布局的首行与末行修改限制在有效范围。
- Diff、并排同步、修改块与本轮变更相关定向测试通过；`./scripts/go vet ./internal/ui`、`./scripts/build` 通过。

原生验收：通过 Cmd+Q 正常退出，进程查询确认退出后直接启动已构建应用，窗口可用。从 Git 更改列表打开实际 `internal/ui/editor_view.go`，第一处新增行（525 行）位于代码区中央；切换并排后，新版本首处新增行仍在中央，原版本对应空白行同步对齐。原生仅验收当前浅色窗口；窄窗口与首尾边界由组件回归覆盖。本轮没有发送模型任务。
