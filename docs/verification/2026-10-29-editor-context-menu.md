# 编辑器右键文件操作验证

日期：2026-10-29。环境：macOS arm64，项目 `./scripts/go` 包装工具链与锁定 MyGo。

## 已实现行为

- 文件树（包括目录和搜索结果）、文件标签和编辑区提供复制路径、复制相对路径、重命名、删除。
- 相对路径从所属工作区根目录计算；编辑区保留原生 Cut、Copy、Paste、Select All。
- 重命名保留未保存内容、选择、撤销与滚动状态，更新路径、标签身份和恢复副本；同名目标使用系统排他重命名保护。
- 删除经弹窗确认后调用系统废纸篓；未保存缓冲先保存恢复副本并继续保留，干净文件关闭标签；操作后刷新文件树、搜索与 Git 状态，立即持久化标签。
- 工作区根、包含已打开工作区的目录、父目录链接到工作区外的目标受保护；读写、检查点及 Git 写操作进行中时提示重试。失败保留原数据并展示具体原因。
