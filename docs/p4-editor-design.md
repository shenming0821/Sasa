# P4：工作区文件与轻量编辑器

> 更新日期：2026-10-24

## 1. 目标与范围

在现有 Codex 工作流中，直接浏览当前工作区、打开和编辑文件、查看 Git 更改。保留 Go + MyGo 原生 UI，以 Orca 的侧栏布局为交互参考，以 Mayoi 的原生编辑器源码为技术参考。

用户已提出的目标：右侧依次为文件、会话历史、Git 三个 Tab；选择文件后，在主窗口以新标签页显示内容。以下为已确认的实现与验收约定，完成状态以实施计划及验证记录为准。

| P4 建议纳入 | 本轮暂缓 |
|---|---|
| 按需文件树、按文件名/相对路径查找、刷新与折叠 | 全工作区内容搜索、替换、文件创建/重命名/删除 |
| 文件与会话共用标签栏，按工作区隔离并恢复打开项 | 预览标签自动替换、多列编辑、拖动分屏 |
| 文本编辑、行号、语法高亮、选择复制、撤销重做、文件内查找 | LSP、补全、诊断、格式化、Vim、插件系统 |
| 显式保存、未保存保护、外部变更检测、异常退出草稿恢复 | 自动保存到源文件、图片/SVG/Markdown 专用预览 |
| Git 分组状态、单文件只读 Diff、未跟踪和冲突状态 | 暂存/取消暂存、丢弃、提交、PR、推送、分支切换、冲突解决器 |

Git 首版展示真实状态和差异；截图中的提交框、加减号、丢弃及 PR 入口，在相应能力单独确认并实现后显示。

交付先形成“文件树 → 打开文件 → 切回会话”的可用闭环，再开放编辑和 Git Diff。P4.0 是限范围的技术验证，不发展成独立编辑器应用；全文的容量与时延均为建议初值，需由 P4 验证后定稿。

## 2. 窗口与视觉

```text
左侧项目栏             主窗口统一标签栏                    右侧工作区侧栏
Fuyu                  [会话 A ×][main.go ● ×][Diff ×]     [文件][历史][Git] [收起]
  main 工作区         项目 / internal / main.go            Fuyu · main
  feature 工作区      行号 | 可编辑文件内容                 查找文件
                      ...                                 internal/
                      UTF-8 · LF · Go · 行:列               main.go
```

- 三个 Tab 固定为第一项“文件”、第二项“会话历史”、第三项“Git”；图标为主，悬停与无障碍名称明确用途，选中图标加深并带底部短横线。首版只有这三个入口。
- 侧栏展开时，“切换右侧边栏”位于侧栏顶栏右端；收起时回到主窗口顶栏。记住上次选中 Tab；已有用户升级后先保留历史 Tab，新安装默认文件 Tab，展开/收起沿用原偏好。
- 常规宽度沿用 320 DIP，窄窗口最小 240 DIP，优先收起左侧项目栏。可用宽度不足以容纳中心 400 DIP、右栏 240 DIP 与分隔线时，临时收起右栏且保留展开偏好，恢复宽度后还原；不靠固定最小宽度把内容挤出窗口。右侧可拖动调宽暂缓。
- 延续 Fuyu 浅灰/白主题和系统 UI 字体；侧栏标题 13 DIP 加粗，文件名 12 DIP 正常字重，路径/状态 11 DIP 灰色；编辑器使用系统等宽字体 13 DIP、约 20 DIP 行高，实际以字体测量对齐行号和内容。
- 沿用主题 Background / Surface / SurfaceHover / Text / TextMuted / Border。状态文字同时使用 M/A/D/? 等标记，避免只靠颜色识别。
- 文件行使用整行统一悬停；按下保持悬停背景，选中态独立。目录箭头在行首表达真实文件层级，常显便于浏览；这与左侧项目分组行尾悬停箭头分别处理。
- 展开/收起采用约 200 ms 过渡并尊重减少动态效果；大目录不为所有子项逐个执行动画。
- 文件内容占满中心可用宽度，不受聊天 800 DIP 阅读栏限制；文件页不显示聊天输入框。底部为文件状态行，错误和加载状态在所属文件页内显示。

## 3. 工作区归属

建立显式 WorkspaceContext（工作区根路径、仓库 common dir、Git 工作树根、显示名称），与当前 Session 分离。

- 点击左侧 worktree，沿用现有进入会话逻辑，同时选择该工作区；点击会话标签，切换到其 cwd 所属最深 worktree。普通文件夹使用其项目根路径。
- 点击文件或 Diff 标签，切换到标签保存的工作区；切换右侧 Tab 只改变面板，不新建或恢复 Codex 会话。
- 会话 cwd 为工作树子目录时，文件树以所属工作树为根，历史仍沿用现有范围语义。嵌套仓库使用用户选中的项目归属，首版不聚合多个仓库状态。
- 文件与 Git 操作绑定启动时的 workspace ID、路径和请求代次。切换工作区、关闭页签后，旧结果不能写进新页面。
- 同一仓库不同 worktree 的文件树、Git index 和文件缓冲分别归属；共用 common dir 只用于项目识别，不能作为文件路径或 Git 命令 cwd。
- 中心没有标签时，保留上次工作区供右侧浏览；没有工作区时显示“选择项目以浏览文件”，不隐式创建会话。

上下文与命令明确分工：

| 状态 / 动作 | 归属规则 |
|---|---|
| ActiveTabID | 唯一决定中心显示与文件快捷键，不能从 `session.open` 推断 |
| ActiveWorkspaceID | 由选中标签或左侧工作区确定；空白中心保留最后值 |
| 当前会话引用 | 仅用于会话操作与协议归属；文件页不能借用它来决定文件路径或新建会话 cwd |
| 文件页点击“新会话” | 在 ActiveWorkspaceID 的根路径新建；未选工作区时先选择目录 |
| 历史“当前项目” | 会话页继续按该会话 cwd 精确匹配；文件/Diff/空白页按工作区根精确匹配，并显示实际范围；P4 不顺带扩展历史查询语义 |
| 关闭当前标签 | 选中混排列表中左邻，否则右邻；关闭非当前项不切换；最后一项关闭后保持空白 |
| 文件页收到审批 | 会话标签/左侧保留待处理标记，主窗口提供返回对应会话的入口，不抢焦点 |

切换工作区取消过时的树、搜索、文件读取/检查、查找和 Git 展示请求；已打开文档的保存与恢复检查点必须完成并回写原文档。关闭页签会使旧加载结果失效，但不能把已提交的文件写入当作可随意取消的读取操作。切回尚未加载的文件时按需重新读取。

## 4. 文件 Tab

- 顶部显示工作区名和分支（普通目录只显示名称）、刷新、全部折叠；下面为“查找文件”。首版按名称和相对路径查找，不显示未实现的“内容”模式。
- 首次只读取根目录，展开时异步读取直接子项；目录优先、名称自然排序，展开状态按工作区保存。可见节点扁平化并虚拟化，避免一次创建全部 UI 行。
- `.git` 元数据不进入树；其他点文件正常显示。Git 忽略项默认灰色显示、允许手动展开，但不进入默认文件名搜索索引；不递归预扫 node_modules 等依赖目录。
- 搜索异步建立受控索引，默认跳过 Git 忽略项；普通目录使用明确的依赖/构建目录排除表。结果显示文件名及相对路径，取消搜索回到原展开位置；达到扫描/结果上限显示截断提示。
- 单击文件立即打开一个持久标签；重复点击已打开文件定位现有标签，不用预览页替换其他文件。打开目录只切换展开，不打开文件标签。
- 普通文件按工作区与系统解析后的绝对路径去重，不统一转小写；符号链接以链接路径保留独立只读页，避免与可写目标合并而绕过只读规则。显示路径保留相对路径；同名标签追加最短可区分父路径，不同 worktree 保持独立。
- 符号链接显示标记，不递归遍历链接目录；指向工作区外的文件首版只读并显示目标归属。循环、失效链接、权限不足分别呈现可重试错误。
- 文件监听合并突发事件，只刷新受影响目录；手动刷新、窗口重新激活作为补充。监听失败保留树并提示刷新，不持续空转。
- 只读取普通文件；FIFO、设备、socket 等特殊项显示类型但不打开读取。打开和保存时重新核对目标类型及链接状态，避免检查后目标被替换。遍历按路径组件判定范围，不使用字符串前缀判断目录归属。

## 5. 主窗口文件标签与编辑

### 标签与状态分离

统一 TabRef：`session | file | diff`，每个 Tab 有稳定 ID、工作区归属、标题和关闭行为。中心按 Tab 类型构建内容；Session 保持原有后台任务、草稿和阅读恢复。

Document 保存路径、TextBuffer、磁盘基线、编码/换行和撤销历史；EditorView 保存光标、选择、滚动和查找状态。Diff 另存比较来源，不冒充可编辑文件。

- Tab 栏按打开顺序混排；文件显示文件图标和文件名，会话保留现有名称，Diff 显示“文件名 · 更改/已暂存”。
- 点击标签切换并恢复各自位置；切换到文件时，Codex 任务继续接收事件，原会话中的审批和完成状态照常维护。
- 文件标签未保存显示圆点；悬停时关闭位置可显示叉号。关闭有改动文件时选择“保存 / 不保存 / 取消”；保存失败保持文件打开并显示原因。
- 关闭最后一个标签显示空白中心，不创建会话。Cmd+W 关闭当前类型标签，原生窗口关闭仍沿用驻留语义。

### 编辑与保存

- 首版支持 UTF-8（含 BOM）、LF/CRLF，保存时保留 BOM、原换行、末尾换行与文件权限；混合换行或其他编码先以只读状态展示原因，避免静默转换。
- 行号与原生文本区域共用滚动和字体测量；默认不折行，支持横向滚动。保留中文输入法组合、选择、复制粘贴、Tab 缩进和原生焦点行为。
- Cmd+Z / Shift+Cmd+Z 撤销重做，历史属于文档；恢复到已保存文本时清除 dirty。Cmd+F 文件内查找、Enter/Shift+Enter 前后匹配、Esc 关闭；Cmd+S 显式保存。
- 文件焦点下 Enter 为换行、Cmd+S 为保存；聊天焦点下继续 Enter 发送、Cmd+Enter 换行。快捷键按焦点和 Tab 类型路由，查找框不触发聊天发送。
- 保存绑定文档 ID、路径、buffer version 和不可变文本快照；同一文档串行保存，重复 Cmd+S 合并为最后一个待保存版本。写入成功只把该快照设为已保存基线，期间的新输入仍为 dirty。
- 磁盘基线包含文件身份、字节内容摘要、编码/换行和必要元数据；mtime/size 只做快速筛选，最终冲突检查比较内容。保存前重新核对，之后同目录临时写入、同步并原子替换；保留权限及可复制的 ACL/扩展属性，无法保留时明确失败，不静默剥离属性。
- 保存失败按阶段报告：替换前失败，原文件不变；替换后同步/核验失败，磁盘可能已更新，保留草稿并重新读取核验，不能提示“原文件未变”。文档保存与恢复副本共享版本校验。
- 普通文件保存无法与外部编辑进程建立跨进程事务；写入前后检查只能缩小竞态窗口，不能保证发现检查与替换之间的全部外部写入。保留最近一次保存前磁盘副本与待写快照，直到完成核验；可观察到冲突时提示，不把此方案描述为无条件防覆盖。
- 干净文档遇到外部更改自动重载并尽量保留位置；有本地编辑时显示“文件已在外部更改”，提供查看磁盘版本、重新载入、明确覆盖。首版不自动合并，也不静默覆盖任一方。
- 外部删除时保留缓冲，允许明确“重新创建文件”或关闭；路径改名无法可靠配对时保留旧页错误，不把另一个文件当成同一文档。链接和硬链接首版只读，避免原子替换破坏链接关系。

### 文件类型与容量

以下为待验证的初始限额，不是实测性能结论：

| 条件 | 首版行为 |
|---|---|
| 普通 UTF-8 文本不超过 4 MiB 且不超过 100,000 行 | 可编辑，后台语法高亮 |
| 超出常规阈值但不超过 16 MiB | 大文件只读模式，关闭高亮等装饰，仍可选择复制 |
| 超过 16 MiB、单行超过 256 KiB | 显示受限提示及系统外部打开入口，不整体载入编辑器 |
| 二进制或无法可靠解码 | 显示类型、大小及外部打开入口，不把字节写回为文本 |

加载使用有界读取并处理文件在读取中增长；多标签内存采用总量预算，不能只依赖单文件限额。

文件内查找首版为字面文本，支持大小写选项；后台搜索绑定文档版本，改动后取消旧任务。正则、全词及替换暂缓。高亮首次优先可见区，后续补齐上下文；超过预算显示纯文本，不能为了等待高亮冻结输入。

## 6. Git Tab

- 顶部显示当前工作树分支与实际 upstream（存在时），刷新按钮；无 Git 目录显示“当前文件夹未使用 Git”。不自动 fetch。
- 折叠分组为“更改”“已暂存的更改”；冲突独立置顶。未跟踪文件进入“更改”，忽略文件不进入状态列表；空组显示空态，保留结构。
- 每行突出文件名，弱化相对父路径，右侧显示状态字母；同一路径同时有 staged 和 unstaged 时同时出现在两组，比较来源分别固定。
- 使用工作树 cwd 执行 `git status --porcelain=v2 -z --branch`；正确解析双路径重命名、空格/换行文件名、未出生 HEAD、detached HEAD、冲突和子模块标记。子模块首版只展示状态，不递归进入其 Diff。
- 点击“更改”文件打开只读 Diff（index → 工作树）；点击“已暂存”打开 HEAD → index。未跟踪文件按空内容 → 工作树显示；新增/删除缺失侧显示空态。冲突文件只读展示当前内容与冲突状态，不虚构单一基线 Diff。
- Diff 首版用带行号的统一差异视图，新增/删除底色并保留文字标记；按可见行渲染，大差异限制读取容量并给出截断提示。二进制只显示状态。
- Git Diff 以磁盘和 index 为准，不包含编辑器未保存内容；同一文件 dirty 时显示“包含未保存编辑，当前差异基于磁盘”，由用户显式保存后刷新。
- 已跟踪文件优先使用 Git 自身生成的 patch，固定关闭彩色、外部 diff 与 textconv；名称、重命名和状态使用 NUL 结构化结果，不能从 patch 标题反推文件路径。保留 mode-only、重命名及“末尾无换行”等元数据。unborn HEAD 的 staged 比较使用 Git 支持的无 HEAD 路径，不写死某种哈希长度的空树 ID。
- 提供“打开文件”进入普通编辑标签；只存在于 index/HEAD 的删除文件不创建空文件。Diff 标签身份含工作区、相对路径及比较种类，两个分组不复用为同一比较页。
- 状态读取、Diff 计算都在后台；关闭面板取消非必要工作，保留上次结果。监听、编辑保存、窗口激活、手动刷新触发合并更新；Git 面板可见时可加低频兜底轮询，不在所有工作区持续扫描。
- Git 参数独立传入，路径使用 NUL 输出解析及字面量 pathspec，禁用外部 diff/textconv 与交互提示，设置取消和容量/时间上限；只读探测使用 `GIT_OPTIONAL_LOCKS=0`。不得因打开页面、刷新或恢复改变 index。
- 读取失败保留上一结果并标明未刷新；不把失败变成“工作区干净”。异步比较结果携带来源版本，基线变化后重新读取，不混用旧 HEAD 与新 index。
- Git 面板隐藏但中心仍显示 Diff 时，该 Diff 继续按需刷新。分别核对当前工作树 git dir 的 index、HEAD 与共享 refs；不只监听工作区中的 `.git` 文件。采样前后状态变化时至多重试一次，继续变化则标明快照可能过时并允许手动重试，避免持续写入导致无休止刷新。

## 7. 技术方案与参考边界

Mayoi 固定参考提交：`2650b9bfa90c87ffe0d48fffb140dd2fc428ff1c`，MIT，2026-10-24 克隆至 `/tmp/fuyu-mayoi-reference-20261024`。源码核验见[参考项目核验](reference-verification.md#13-mayoip4-轻量原生编辑器参考)。

| 已核对机制 | Fuyu 采用方式 |
|---|---|
| MyGo TextBuffer / TextAreaBufferBase，document 与 editor 分离 | 用现有原生输入和持久文本树；先验证中文输入及视口，再接业务 |
| TextSnapshot 保存撤销基础，可见行 TextRanges 绘制 | 按文档保留撤销与缓存，只为可见区域生成高亮范围 |
| Chroma 后台词法高亮，可见区域优先、版本校验 | 引入独立可取消 worker，文本变化后过期结果丢弃，纯文本作为即时降级 |
| workspace Tree 按目录加载、fsnotify 合并事件 | 按工作区管理监听生命周期，避免全量递归订阅 |
| Git CLI porcelain v2 与分组视图 | 复用结构思想，独立实现本轮只读子集 |

Mayoi 的 go.mod 将 MyGo replace 为 `github.com/sorrycc/mygo` 提交 `4bd079439ee7`；Fuyu 仍锁定 `github.com/egoist/mygo` 提交 `976f17c9391f`，另有输入兼容补丁。已在 Fuyu 本地依赖找到 TextBuffer、Snapshot、TextAreaBufferBase、TextRanges、TrackLines，但这只证明 API 存在，不能证明 Mayoi 编辑器可直接编译或输入行为一致。

先做兼容性验证，保留 Fuyu 当前依赖；若缺能力，列出最小补丁及回归范围，再决定补丁或升级。引入 Chroma/fsnotify 时固定经过构建验证的版本。直接移植 MIT 代码时保留版权及许可，并登记实际来源文件；不将整个 Mayoi 应用作为运行依赖。

## 8. 恢复与资源管理

- 升级数据库到 schema 3：先校验旧 JSON 并保留一致性备份，再在事务内提升版本。已有有效旧备份时另建本次快照，损坏备份报错并保留来源。旧 JSON 由 UI 兼容读取，首次成功保存时将带类型、有序 WorkspaceTabs、ActiveTabID 与 Session 索引同事务写入；新字段作为唯一打开标签来源，明确空数组表示空白。旧版程序通过高版本拒绝逻辑停止写入，避免旧快照丢弃文件标签/恢复引用。
- OpenTabs 缺失的旧记录仅迁移选中会话；显式空数组保持空白；已有数组保留顺序并去重。Selected 失效时选首个有效标签，无有效项则空白。显式 cwd 启动沿用现有目录会话打开规则，保留其他标签；文件缺失保留可关闭错误页。未知标签类型报告兼容错误并保留记录。
- 恢复入口不得再以 `len(Sessions)==0` 提前返回；纯文件标签工作区同样恢复布局、工作区和草稿。Session 索引与新 Tab 状态同事务保存，运行任务的归属仍由原会话维护。
- 保存每个文件的工作区、相对路径、光标、滚动位置，以及每个工作区的展开目录、选中面板。干净文件正文不写数据库，重启按需读取磁盘；只恢复标签元数据，不批量载入所有文件或启动 Codex。
- 编辑草稿使用独立、仅当前用户可读的恢复副本，与磁盘基线和文档版本一起保存；不覆盖源文件，不随每次全局快照把正文整份写进会话 JSON。恢复目录权限 0700、文件 0600，以应用生成的文档 ID 命名，不用源路径作为可写相对路径。
- 检查点采用自包含记录，包含文档身份、磁盘基线、编辑正文、版本和文本摘要；按“同目录临时写入 → 同步文件 → 原子替换 → 同步目录”执行，不依赖数据库引用才能恢复。每个文档串行提交，旧异步任务不能覆盖新版本。启动扫描所有有效副本并提供恢复，不因缺少标签引用直接删除；损坏副本保留并报告，其他有效副本继续加载。源文件保存成功后，只有当前缓冲确实干净才清理恢复记录，防止删除保存期间新增编辑；清理失败保留错误和副本。
- 建议输入停顿 1 秒写恢复副本，持续输入最长 5 秒做一次检查点；明确正常退出可等待写入，突然崩溃可能丢失最近一个检查点间隔。容量纳入总预算；写入失败在文件页持续提示。
- 重启遇到恢复草稿时，与最新磁盘内容核对后恢复编辑；磁盘已变保留两版并提示。正常退出先检查未保存项与活动任务并收集决定，再按原有流程停止任务；等待期间再次出现文件变更时重新检查冲突，最后保存或丢弃草稿并退出。取消/停止超时返回应用时不提前执行丢弃，不清理恢复副本；不能先保存文件再允许仍运行的任务覆盖后直接退出。
- 窗口关闭驻留保留编辑与任务，尝试立即写恢复检查点。再次退出进入同一退出协调器，避免多个对话框并行；强退沿用任务边界并说明恢复副本可能落后于最新输入。
- 当前工作区持有目录监听；其他工作区只为已打开文档保留必要的父目录监听或按需核验。切回标签和保存前始终检查磁盘；释放无引用 watcher/timer/worker。隐藏视图不持续重排或绘制，结果经主线程派发，组件 Element 不跨构建阶段持有。

### 初始资源预算与退让顺序

以下作为 P4 的资源验收预算；已接入并发与容量限制，具体覆盖及尚待验证的边界见验证记录。P4.0/P4.5 记录测量后可调整，并同步依据：

| 资源 | 初始预算 | 达到上限后的行为 |
|---|---|---|
| 文件读取/目录枚举 | 全局最多 2 个并发任务；目录、搜索、磁盘检查和查找共用最多 1 个后台槽 | 为显式打开文件保留读取机会，取消过时读取 |
| 文件名索引 | 当前工作区最多 100,000 路径或 16 MiB 路径文本，200 条显示结果 | 标明结果截断，允许收窄搜索；不无限积累其他工作区索引 |
| Git | 每工作区最多 1 个状态请求；全局最多 2 个 Git 子进程；单请求 5 秒、输出 8 MiB | 取消并显示超时/受限，保留旧结果；不将截断结果作为完整状态 |
| 文档缓存 | 可重建的干净文本总量 64 MiB | 淘汰最久未访问的隐藏干净文档，标签和位置保留 |
| 撤销与高亮 | 撤销按新增保留文本估算全局 32 MiB，高亮缓存 16 MiB | 优先释放隐藏高亮，再缩减最旧撤销记录；不丢当前 dirty 文本 |
| 未保存文本 / 恢复副本 | 当前 dirty 文本总量 64 MiB；恢复目录预算 256 MiB | 阻止继续扩张并提示先保存/关闭；保留现有内容、孤立副本及失败证据，不能为腾空间自动丢弃 |

这些预算分别计量，不等同于进程 RSS 硬上限。文本树共享节点、原生排版和 Git 输出仍需实测；检查大粘贴/大编辑前的容量，超限操作整体拒绝而不截断文本。保存操作有独立串行队列，不被搜索队列挤占。

建议性能验收样本：10,000 路径工作区、10,000/100,000 行文本、超长行、20 个混合标签，以及 Agent 批量改写。首屏文件树、常规文件打开目标分别在 300/200 ms 内出现可交互内容；滚动和输入主要帧工作目标在 16.7 ms 内。记录设备、样本大小、冷/热缓存及测量方法；超限时先降级高亮与索引，不阻塞消息接收。这些是目标，不引用 Mayoi 数字作为 Fuyu 结果。

测试分层：纯模块使用临时目录/临时 Git；MyGo 组件覆盖边界、焦点、快捷键和中间动画帧；原生窗口覆盖中文输入、剪贴板、拖动窗口与混合标签切换；真实 Codex 只验证后台运行/外部改写联动，不用真实项目数据制造冲突。

关键放行用例必须包含：

1. 会话 A 运行中切到工作区 B 的文件，新建会话/历史范围/保存都属于 B，审批仍返回 A。
2. 迁移缺失/空 OpenTabs、纯文件标签、失效选中项；迁移失败回滚，旧版拒绝写 schema 3。
3. 保存版本 v1 期间继续输入 v2，v1 完成后 v2 仍 dirty 且有恢复副本；双次保存按顺序执行。
4. 磁盘同大小/同时间戳改写仍能检出；保存各阶段故障分别报告，外部删改、链接替换不误写。
5. 在检查点临时写入、原子替换前后、恢复副本清理三个位置模拟中断，至少保留最近已完成检查点；容量不足、磁盘满和损坏不得清空已有恢复数据。分别记录模拟文件状态、实际进程崩溃和真实磁盘故障的证据。
6. 同一文件同时 staged/unstaged、有未保存缓冲、改名及只改权限时，分组/比较来源正确；读取前后 index 与 refs 无写入。
7. 退出等待期间外部改写、用户取消退出、停止超时返回应用，不提前丢弃草稿；最窄窗口与隐藏 Diff 刷新保持可操作。

### 焦点、比较页与状态细节

- 打开文件时记录一次焦点请求；异步加载完成后，仅在该文件仍为当前标签、用户未把焦点移到其他控件且没有模态框时执行。新文件光标从开头开始，已打开文件保留原选择和光标。
- 文件内查找与文件树查找分别处理 Esc；只关闭或清空当前焦点所属的查找，不同时改变其他面板。模态确认优先接收键盘，取消后恢复原焦点；快捷键由当前区域消费一次。
- 冲突比较页属于只读 Diff，但比较类型为“本地编辑 ↔ 磁盘版本”，与 Git 两种比较分开；标题明确“外部更改”。打开时固定两侧文本版本，后续变化显示“比较已过时”及刷新入口，不静默替换用户正在核对的内容。
- 冲突比较页关闭不丢弃编辑，重新载入/覆盖从原文件的冲突提示发起；点击确认前再次核对磁盘版本，磁盘继续变化则回到冲突提示。
- 面板搜索、结果和滚动只在当前进程按工作区保存；重启恢复文件树展开目录、上次面板和文件阅读位置，搜索结果重新获取。此处不增加跨重启搜索缓存。
- 右侧历史筛选沿用第 3 节定义的实际范围；结果变化后保留有效的列表位置，原条目已不存在时就近定位，不能恢复到超出列表的空白区域。

### 动效与提示

- 目录展开/收起沿用约 200 ms 动效，选中反馈轻量呈现；标签切换直接显示内容，不做整页滑动。大目录使用裁剪与可见行更新，减少动态效果开启时立即完成状态切换。
- 工具栏图标保留简短功能提示；目录行不添加动作或路径气泡，文件路径通过编辑器顶部查看。无障碍名称与键盘焦点样式始终保留。
- 保存成功等正常完成状态不弹通知；加载失败、保存失败和冲突在所属面板/文件内持续显示，直到解决或用户关闭该页。后台会话的待处理状态通过可返回会话的入口呈现。
